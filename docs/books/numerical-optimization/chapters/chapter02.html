알고리즘이 이동을 멈췄다는 사실만으로 좋은 답을 찾았다고 말할 수는 없다. 이 장은 해의 정의, 미분을 이용한 판정, 실제 반복을 만드는 방법을 한 흐름으로 연결한다. 특히 “기울기 0”, “양의 곡률”, “작은 이동”이 각각 어떤 정보를 주는지 구분한다.

학습 목표와 준비

  • 국소·엄격 국소·고립 국소·전역 최소의 비교 범위를 설명한다
  • 일차 필요조건과 이차 필요·충분조건의 가정을 확인한다
  • 선 탐색과 신뢰영역, 최급강하와 뉴턴의 역할을 나누어 이해한다
  • 변수의 단위가 반복 경로와 종료 조건에 미치는 영향을 관찰한다

선수 지식은 편미분, 벡터 내적, 대칭행렬의 고유값이다. g=∇f(x)g=\nabla f(x)g=∇f(x)는 기울기, B=∇2f(x)B=\nabla^2f(x)B=∇2f(x)는 헤시안을 뜻한다. 이번 장의 미분 판정은 제약이 없는 열린 근방에서 사용한다.

2.1 해의 정의부터 확인한다

x∗x^*x∗가 국소 최소라는 것은 어떤 양수 ε\varepsilonε를 골랐을 때 그 근방에서 더 작은 함수값이 없다는 뜻이다.

∥x−x∗∥<ε⟹f(x∗)≤f(x).\|x-x^*\|<\varepsilon \quad\Longrightarrow\quad f(x^*)\leq f(x).∥x−x∗∥<ε⟹f(x∗)≤f(x).

비교 대상을 모든 점으로 넓히면 전역 최소다. 근방의 다른 모든 점에서 부등호가 엄격해지면 엄격 국소 최소다. 고립 국소 최소는 근방에 다른 국소 최소점이 없다는 뜻이므로, 비교하는 대상 자체가 다르다. 엄격 최소 근처에 더 높은 값을 갖는 다른 작은 골짜기들이 있을 가능성과 원래 점보다 낮은 값이 있을 가능성은 같은 질문이 아니다.

이 구분은 수치 결과를 서술할 때도 필요하다. “여러 초기값에서 같은 점에 도착했다”는 유용한 관측이지만, 모든 초기값을 확인했다거나 전역 최적성을 증명했다는 뜻은 아니다. 반대로 목적함수의 볼록성을 증명했다면 국소 정보로 전역성을 말할 근거가 생긴다.

2.2 일차 조건: 모든 방향을 살펴본다

함수가 미분 가능하고 x∗x^*x∗가 내부 국소 최소이면 기울기는 0이어야 한다. 기울기가 0이 아니라면 p=−gp=-gp=−g 방향의 방향미분이 음수이기 때문이다.

Df(x)[p]=gTp,gT(−g)=−∥g∥2<0(g≠0).D f(x)[p]=g^Tp, \qquad g^T(-g)=-\|g\|^2<0\quad(g\ne0).Df(x)[p]=gTp,gT(−g)=−∥g∥2<0(g=0).

따라서 충분히 작은 양의 이동은 비용을 낮춘다. 그러나 기울기 0은 필요조건이지 충분조건이 아니다. f(t)=t3f(t)=t^3f(t)=t3의 원점은 수평 접선을 갖지만 최소가 아니다. 여러 변수에서는 어느 방향으로는 올라가고 다른 방향으로는 내려가는 안장점도 있다.

필요조건을 잘못 적용하는 두 경우도 기억하자. 첫째, 제약의 경계에서는 감소 방향이 허용되지 않을 수 있다. 둘째, f(t)=∣t∣f(t)=|t|f(t)=∣t∣는 원점에서 최소지만 고전적 미분이 존재하지 않는다. 비매끄러운 문제에는 방향미분이나 부분기울기 같은 다른 도구가 필요하며, 미분 불능을 기울기 0으로 임의 치환해서는 안 된다.

2.3 이차 조건: 평평한 곳의 굽음을 읽는다

두 번 연속 미분 가능한 함수는 가까운 변위 ppp에 대해 다음처럼 근사된다.

f(x+p)=f(x)+gTp+12pTBp+o(∥p∥2).f(x+p)=f(x)+g^Tp+\tfrac12p^TBp+o(\|p\|^2).f(x+p)=f(x)+gTp+21​pTBp+o(∥p∥2).

정상점에서는 일차항이 사라져 이차항이 먼저 보인다. 국소 최소의 헤시안은 양의 준정부호여야 한다. 어떤 방향에서 pTBp<0p^TBp<0pTBp<0이면 그 방향의 작은 이동이 함수값을 낮추기 때문이다. 반대로 정상점의 헤시안이 양의 정부호이면 엄격 국소 최소가 된다.

국소 최소⟹g=0,B⪰0,g=0,B≻0⟹엄격 국소 최소.\begin{aligned} \text{국소 최소}&\Longrightarrow g=0,\quad B\succeq0,\\ g=0,\quad B\succ0&\Longrightarrow\text{엄격 국소 최소}. \end{aligned}국소 최소g=0,B≻0​⟹g=0,B⪰0,⟹엄격 국소 최소.​

양의 준정부호와 양의 정부호 사이에는 중요한 빈칸이 있다. t4t^4t4와 −t4-t^4−t4는 원점에서 기울기와 이차 미분이 모두 0인데 한쪽은 최소, 다른 쪽은 최대다. 영 고유값이 나오면 검사가 불충분하다는 결론을 내려야지, 자동으로 최소라고 표시하면 안 된다.

테일러 근사는 국소 도구다. “헤시안이 현재의 곡률을 잘 설명한다”와 “멀리 떨어진 곳에서도 이차식이 정확하다”는 다른 주장이다. 다음 두 전략은 바로 이 모델의 유효 범위를 관리하는 방법이다.

2.4 반복 알고리즘은 방향과 크기를 함께 정한다

선 탐색은 먼저 방향 pkp_kpk​를 만든 뒤 단계 길이 αk>0\alpha_k>0αk​>0를 고른다.

xk+1=xk+αkpk.x_{k+1}=x_k+\alpha_kp_k.xk+1​=xk​+αk​pk​.

최급강하는 pk=−gkp_k=-g_kpk​=−gk​를 사용한다. 단위 유클리드 길이의 방향 중 일차 감소가 가장 크다는 의미다. 하지만 실제로 유한 거리를 이동했을 때 가장 좋은 방향이라는 뜻은 아니다. 좌표마다 곡률이 크게 다르면 가파른 방향을 번갈아 따라가느라 진전이 느릴 수 있다.

뉴턴 방향은 이차 모델의 정상점을 계산한다.

Bkpk=−gk.B_kp_k=-g_k.Bk​pk​=−gk​.

양의 정부호 BkB_kBk​에서는 gkTpk=−gkTBk−1gk<0g_k^Tp_k=-g_k^TB_k^{-1}g_k<0gkT​pk​=−gkT​Bk−1​gk​<0이어서 하강 방향이다. 헤시안이 부정부호이면 이 결론이 사라진다. 예를 들어 f(u,v)=u2−v2f(u,v)=u^2-v^2f(u,v)=u2−v2에서 (0,1)(0,1)(0,1)의 뉴턴 단계는 원점으로 향한다. 비용은 −1-1−1에서 0으로 올라가므로, 정상점을 찾는 계산과 최소화는 분명히 다르다.

신뢰영역은 먼저 “현재 모델을 믿을 수 있는 범위”를 제한한 다음, 그 안에서 방향과 크기를 동시에 정한다. 준뉴턴은 이전 기울기 변화로 곡률을 근사하고, 비선형 켤레기울기는 이전 방향을 재사용해 저장량을 줄인다. 이름보다 중요한 것은 각 방법이 어떤 정보를 필요로 하고, 그 정보가 틀릴 때 어떻게 안전장치를 두는가이다.

2.5 손계산: 같은 해로 향하는 두 경로

다음 엄격 볼록 이차함수를 새 실험으로 사용한다.

f(u,v)=12(u−1)2+8(v+0.5)2.f(u,v)=\tfrac12(u-1)^2+8(v+0.5)^2.f(u,v)=21​(u−1)2+8(v+0.5)2.

해는 (1,−0.5)(1,-0.5)(1,−0.5)이고 헤시안은 Q=diag⁡(1,16)Q=\operatorname{diag}(1,16)Q=diag(1,16)이다. 시작점을 (−2,1.5)(-2,1.5)(−2,1.5)로 잡으면 기울기는 (−3,32)(-3,32)(−3,32)다. 뉴턴 방정식은 (p1,16p2)=(3,−32)(p_1,16p_2)=(3,-32)(p1​,16p2​)=(3,−32)이므로 p=(3,−2)p=(3,-2)p=(3,−2), 즉 한 번의 전체 단계로 정확한 해에 도착한다. 이는 헤시안이 어디서나 같은 이차함수이기 때문에 가능한 결과다.

α=gTggTQg=103316393≈0.0630.\alpha=\frac{g^Tg}{g^TQg} =\frac{1033}{16393}\approx0.0630.α=gTQggTg​=163931033​≈0.0630.

2.6 스케일링은 표시 방식 이상이다

변수 변환을 x=x∗+Dzx=x^*+Dzx=x∗+Dz, D=diag⁡(1,1/4)D=\operatorname{diag}(1,1/4)D=diag(1,1/4)로 두면 이차항의 행렬은 다음처럼 바뀐다.

DTQD=I.D^TQD=I.DTQD=I.

같은 물리적 문제라도 새 좌표에서는 등고선의 곡률이 균형을 이룬다. 원래 좌표의 조건수는 16, 변환된 좌표의 조건수는 1이다. 최급강하는 선택한 좌표의 유클리드 기하를 사용하므로 이러한 변환에 영향을 받는다. 뉴턴은 정확한 선형계 풀이와 적절한 변환을 가정하면 선형 좌표 변화에 더 자연스럽게 대응한다.

종료 조건도 단위를 고려해야 한다. 목적값의 변화만 작으면 평평한 구간에서 멈출 수 있고, 이동량만 작으면 너무 작은 단계 때문에 멈출 수 있다. 기울기 노름, 상대 이동량, 목적값 변화, 최대 반복 제한과 실패 사유를 함께 기록하자. 숫자 하나를 임의로 0과 비교하기보다 문제의 크기에 맞는 절대·상대 허용 오차를 정한다.

독립 실험과 읽는 법

독립 실행 예제 내려받기는 정확 선 탐색 최급강하와 뉴턴 한 단계를 직접 계산한다. 코드가 사용하는 알려진 해는 알고리즘 입력이 아니라 검증 기준이다. 스케일 변환 뒤의 행렬도 별도로 계산한다.

그림 확대

새 실행에서 뉴턴 해 오차는 0, 최급강하 반복은 23회, 마지막 기울기 노름은 약 6.79×10−116.79\times10^{-11}6.79×10−11이었다. 매 단계 비용이 증가하지 않았고, 스케일링 뒤 조건수가 1임을 단언문으로 확인했다. 이 반복 횟수는 여기의 시작점·행렬·종료 조건에 대한 결과이며 방법 전체의 순위표가 아니다.

자주 하는 실수

  • 양의 준정부호 헤시안을 충분조건으로 쓴다: 영 곡률 방향의 고차항이 남을 수 있다
  • 뉴턴 방향은 항상 하강한다고 가정한다: 헤시안의 정칙성과 양정성을 따로 검사한다
  • 한 단계 종료를 일반화한다: 이번 함수는 정확한 이차 모델 그 자체다
  • 두 그림의 축 비율을 무시한다: 길쭉한 등고선을 해석할 때 좌표 단위와 화면 비율을 모두 본다

  • 이차함수의 뉴턴 한 단계가 해 (1, -0.5)에 도달
  • 스케일 변환으로 헤시안 조건수 16을 1로 변경

Python 코드 읽기
#!/usr/bin/env python3
"""Original, self-contained teaching experiment. Not a production optimizer.
Run: python chapter02.py --output-dir ./output
Only NumPy, SciPy and Matplotlib are required. No network or private data.
"""
from pathlib import Path
import argparse, json, os, platform, tempfile
os.environ.setdefault("MPLCONFIGDIR", str(Path(tempfile.gettempdir()) / "optimization-learning-mpl"))
os.environ.setdefault("XDG_CACHE_HOME", str(Path(tempfile.gettempdir()) / "optimization-learning-cache"))
Path(os.environ["XDG_CACHE_HOME"]).mkdir(parents=True, exist_ok=True)
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser(description=__doc__)
parser.add_argument("--output-dir", type=Path, default=Path("."))
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"),
              Path("/usr/share/fonts/truetype/nanum/NanumGothic.ttf")]
korean = False
for font_path in font_paths:
    if font_path.exists():
        font_manager.fontManager.addfont(str(font_path))
        plt.rcParams["font.family"] = font_manager.FontProperties(fname=str(font_path)).get_name()
        korean = True
        break
plt.rcParams.update({"axes.unicode_minus": False, "font.size": 10,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f8fafc", "axes.facecolor": "#f8fafc"})
def label(ko, en):
    return ko if korean else en

def finish(chapter, fig, results):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160, bbox_inches=None)
    plt.close(fig)
    results.update({"chapter": chapter, "seed": 20261001,
                    "python": platform.python_version(), "numpy": np.__version__,
                    "scipy": scipy.__version__, "matplotlib": matplotlib.__version__,
                    "korean_labels": korean, "checks_passed": True})
    output = json.dumps(results, ensure_ascii=False, indent=2, allow_nan=False)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(output + "\n", encoding="utf-8")
    print(output)

Q = np.diag([1.0, 16.0])
star = np.array([1.0, -0.5])
x0 = np.array([-2.0, 1.5])
def f(x):
    d = x-star
    return 0.5*float(d @ Q @ d)
path=[x0.copy()]
for _ in range(100):
    x=path[-1]
    g=Q@(x-star)
    if np.linalg.norm(g) < 1e-10:
        break
    alpha=float(g@g)/float(g@Q@g)
    path.append(x-alpha*g)
path=np.array(path)
g0=Q@(x0-star)
newton=x0-np.linalg.solve(Q,g0)
D=np.diag([1.0, 0.25])
transformed=D.T@Q@D
assert np.linalg.norm(newton-star) < 1e-12
assert np.linalg.norm(transformed-np.eye(2)) < 1e-12
assert np.max(np.diff([f(x) for x in path])) <= 1e-12
assert np.linalg.norm(Q@(path[-1]-star)) < 1e-8
fig, ax=plt.subplots(1,2,figsize=(10,4.5),layout="constrained")
u,v=np.meshgrid(np.linspace(-2.4,2.4,300),np.linspace(-1.6,1.8,250))
z=.5*((u-1)**2+16*(v+.5)**2)
ax[0].contour(u,v,z,levels=[.1,.5,1,2,4,8,16,32],colors="#a5b4fc",linewidths=.8)
ax[0].plot(path[:,0],path[:,1],"o-",ms=3,color="#0f766e",label=label("최급강하 · 정확 선 탐색","Steepest descent"))
ax[0].plot([x0[0],newton[0]],[x0[1],newton[1]],"--",color="#ea580c",label=label("뉴턴 한 단계", "One Newton step"))
ax[0].scatter(*star,s=80,marker="*",color="#0f172a",zorder=6)
ax[0].set(xlabel="u",ylabel="v",title=label("방향 선택이 바꾸는 경로","Direction changes the path"),aspect="equal")
ax[0].legend(fontsize=8,loc="upper right")
errors=np.linalg.norm(path-star,axis=1)
ax[1].semilogy(range(len(errors)),np.maximum(errors,1e-16),"o-",ms=3,color="#0f766e")
ax[1].set(xlabel=label("반복 번호", "Iteration"),ylabel=label("해까지의 거리", "Distance to solution"),
          title=label("작은 기울기와 알려진 해를 대조", "Check gradient and known solution"))
ax[1].grid(alpha=.2,which="both")
finish(2,fig,{"minimizer":star.tolist(),"initial_gradient":g0.tolist(),
              "newton_solution_error":float(np.linalg.norm(newton-star)),
              "steepest_iterations":len(path)-1,"steepest_gradient_norm":float(np.linalg.norm(Q@(path[-1]-star))),
              "original_condition_number":float(np.linalg.cond(Q)),"scaled_condition_number":float(np.linalg.cond(transformed)),
              "all_objectives_nonincreasing":True})
