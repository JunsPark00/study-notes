이차계획법(QP)은 이차 목적함수와 선형 제약을 가진다. 최소제곱, 배분, 제어에서 직접 등장하고, 비선형 최적화의 국소 모델로도 반복해서 풀린다. 제약이 선형이라고 모든 QP가 쉬운 것은 아니다. 곡률이 양수인지, 제약의 자유 방향에서만 양수인지, 활성집합이 알려져 있는지가 해법을 좌우한다.

학습 목표와 가정

  • 등식 QP의 KKT 선형계를 유도한다
  • 전체 헤시안과 축약 헤시안의 양의 정부호성을 구분한다
  • 활성집합에서 제약을 추가하거나 제거하는 기준을 설명한다
  • 직접 풀이, 반복 풀이, 투영, 내부점 접근의 역할을 비교한다

문제는 q(x)=12xTHx+gTxq(x)=\tfrac12x^THx+g^Txq(x)=21​xTHx+gTx를 최소화하는 것이며 H=HTH=H^TH=HT로 둔다. 부등식은 c(x)=Ax+b≥0c(x)=Ax+b\ge0c(x)=Ax+b≥0, 라그랑지안은 L=q−λTcL=q-\lambda^TcL=q−λTc로 쓴다. 따라서 정상성은 Hx+g−ATλ=0Hx+g-A^T\lambda=0Hx+g−ATλ=0, 부등식 승수는 λ≥0\lambda\ge0λ≥0이다. 이 표기에서는 상한 x+y≤2x+y\le2x+y≤2를 2−x−y≥02-x-y\ge02−x−y≥0으로 입력한다.

16.1 등식 QP의 해는 접공간 곡률에 달려 있다

먼저 Ax=bAx=bAx=b만 있는 경우를 보자. 등식 승수에는 부호 제한이 없으며 L=q−λT(Ax−b)L=q-\lambda^T(Ax-b)L=q−λT(Ax−b)에서 다음 시스템을 얻는다.

[H−ATA0][xλ]=[−gb].\begin{bmatrix}H&-A^T\\A&0\end{bmatrix} \begin{bmatrix}x\\\lambda\end{bmatrix} =\begin{bmatrix}-g\\b\end{bmatrix}.[HA​−AT0​][xλ​]=[−gb​].

이 식은 정상점 조건이므로 해를 얻었다고 곧바로 최소점이라고 결론 내리지 않는다. AAA가 행 독립이고 ZZZ의 열이 AAA의 영공간 기저일 때 ZTHZ≻0Z^THZ\succ0ZTHZ≻0이면 등식 실행 가능 집합 위의 목적이 엄격 볼록이다. 실행 가능한 점이 존재하면 유일한 최소점을 얻는다. HHH 자체가 양의 정부호이면 충분하지만 필수는 아니다. 제약이 금지한 방향의 음의 곡률은 실행 가능한 이동에 영향을 주지 않을 수 있다.

반대로 축약 헤시안이 특이하면 해가 여러 개이거나 선형항 때문에 아래로 비유계일 수 있다. “헤시안에 0 고유값이 있다”는 사실 하나로 결과를 정하지 말고 해당 방향의 제약과 선형항까지 확인한다.

16.2 직접 풀이의 세 가지 시각

KKT 계를 그대로 풀면 변수와 승수를 동시에 얻는다. 대칭 형태로 행 부호를 조절할 수 있지만 일반적으로 부정부호 계이므로 양의 정부호 행렬용 Cholesky 분해를 무조건 적용해서는 안 된다. 안정적인 피벗을 포함한 분해와 잔차 검사가 중요하다.

영공간 방법은 x=xp+Zpx=x_p+Zpx=xp​+Zp로 두어 등식을 먼저 만족시키고 ZTHZZ^THZZTHZ 계를 푼다. 자유도가 작을 때 유리할 수 있으나 명시적인 ZZZ를 만들면 희소성이 사라질 수 있다. 범위공간 방법은 HHH가 가역일 때 xxx를 소거하여 승수 계를 만든다. 이때도 H−1H^{-1}H−1를 실제로 저장하는 것이 아니라 선형계 풀이를 재사용하는 식으로 구현한다.

어느 방식이 좋은지는 행렬 크기만으로 결정되지 않는다. 제약 수, 희소 구조, 수치적 조건, 분해를 재활용할 가능성을 살핀다. 이번 실습에서는 구조를 드러내기 위해 작은 조밀 KKT 계를 직접 푼다.

16.3 반복 풀이와 전처리

큰 희소 문제에서는 KKT 계의 정확한 조밀 분해가 비싸다. 반복 선형 솔버는 행렬과 벡터의 곱을 이용해 근사해를 얻으며 전처리가 수렴 속도를 크게 바꾼다. 표준 CG는 대칭 양의 정부호 계를 전제로 하므로 부정부호 KKT 계에 그대로 사용하는 것은 적절하지 않다. 적절한 축약 계나 부정부호용 반복 방법을 선택해야 한다.

하위 선형계를 지나치게 정확히 푸는 것도 낭비일 수 있다. 바깥 최적화 반복이 아직 멀리 있다면 필요한 수준의 근사 방향만 구할 수 있다. 반대로 부정확한 방향으로 최종 종료 기준을 만족했다고 보고하면 안 된다. 선형계 잔차와 최적화의 KKT 잔차를 따로 기록하는 습관이 도움이 된다.

16.4 부등식 QP와 16.5 활성집합 반복

볼록 QP에서 실행 가능성, 비음수 승수, 정상성, 상보성이 성립하면 전역 최적성을 인증할 수 있다. 활성집합 방법은 현재 점에서 등식으로 취급할 제약의 부분집합, 즉 작업집합을 유지한다. 작업집합의 법선에 직교하는 방향으로 등식 QP를 풀어 이동한다.

방향 ppp가 0이 아니면 다른 제약을 넘지 않는 최대 단계까지 이동한다. 이동을 막은 제약을 작업집합에 추가한다. 방향이 0이면 현재 면 위에서는 더 개선할 수 없다는 뜻이다. 이때 작업집합 승수가 모두 비음수이면 최적성 인증이 되고, 음수 승수가 있으면 그 제약을 풀어 주어야 개선 가능성이 열린다. 실행 가능한 시작점, 독립적인 작업집합, 퇴화 처리 등은 구현에서 별도로 관리해야 한다.

16.6 QP 내부점과 16.7 기울기 투영

QP 내부점은 양수 slack과 승수를 유지하며 상보성 곱을 작은 양수로 완화한다. LP와 달리 정상성 선형화에 HHH가 포함된다. 양의 준정부호 HHH와 선형 제약을 갖는 볼록 문제에서는 구조를 활용할 수 있지만, 특이성·퇴화·스케일에 대한 수치 대책은 여전히 필요하다. 경계 가까이 가는 반복과 최적 활성집합을 명시적으로 얻는 과정도 구분한다.

상자 제약에서는 투영된 기울기 단계 x+=P[l,u](x−α∇q(x))x^+=P_{[l,u]}(x-\alpha\nabla q(x))x+=P[l,u]​(x−α∇q(x))가 특히 간단하다. 각 성분을 상·하한 사이로 잘라 주면 되기 때문이다. 이때 단순 기울기 노름은 경계 최적점에서 0이 아닐 수 있다. 대신 투영된 기울기 사상이나 KKT 잔차를 써야 한다. 일반 다면체 투영은 그 자체가 QP여서 상자 제약만큼 공짜가 아니다.

이 장의 삼각형 제약을 단순히 각 성분마다 잘라내면 합 제한은 보장되지 않는다. 투영 연산의 대상 집합을 정확히 정하는 것이 중요하다. 여러 간단한 제약을 차례로 투영하는 방식과 교집합으로의 정확한 유클리드 투영은 일반적으로 같지 않다.

16.8 비선형 최적화에서의 역할

SQP에서는 제약을 선형화하고 라그랑지안의 곡률을 이용해 매번 QP를 만든다. 따라서 QP 해의 의미를 이해하면 다음 단계에서 왜 승수를 갱신하는지, 왜 곡률을 정칙화하는지 자연스럽게 연결된다. 다만 원래 문제는 비선형이므로 QP가 최적이어도 원래 제약을 정확히 만족하지는 않을 수 있다.

볼록 QP의 강한 인증을 일반 비볼록 QP에 그대로 옮기지 않는다. KKT 점이어도 최소점이 아닐 수 있고, 음의 곡률 방향을 다뤄야 할 수 있다. 지역적 해석과 전역적 인증을 구분하는 것이 방법 이름을 외우는 것보다 중요하다.

주의점과 연습

  • 행렬 HHH를 비대칭으로 입력했다면 목적에는 대칭 부분만 기여하지만 기울기 코드는 잘못될 수 있다
  • 활성 제약을 너무 많이 넣어 기울기가 종속되면 KKT 계가 특이해질 수 있다
  • 승수 부호는 제약을 ≥0\ge0≥0로 썼는지 ≤0\le0≤0로 썼는지와 함께 읽는다

args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc")]

from itertools import combinations
from scipy.optimize import minimize

H=np.array([[4.,1.],[1.,2.]]); g=np.array([-8.,-3.])
A=np.array([[-1.,-1.],[1.,0.],[0.,1.]])
b=np.array([2.,0.,0.])  # c(x)=A x+b >=0; L=q-lambda.T c.
def f(x): return .5*x@H@x+g@x
x=np.zeros(2); active=[1,2]; path=[x.copy()]
for iteration in range(20):
    W=A[active]; k=len(active)
    K=np.block([[H,-W.T],[W,np.zeros((k,k))]])
    sol=np.linalg.solve(K,np.r_[-(H@x+g),np.zeros(k)])
    p,lam=sol[:2],sol[2:]
    if np.linalg.norm(p,np.inf)<1e-11:
        if k==0 or lam.min()>=-1e-10:
            break
        active.pop(int(np.argmin(lam)))
        continue
    alpha=1.; blocker=None
    for j in range(3):
        if j not in active and A[j]@p < -1e-12:
            bound=-(A[j]@x+b[j])/(A[j]@p)
            if bound < alpha-1e-12:
                alpha=bound; blocker=j
            elif abs(bound-alpha)<1e-12 and blocker is None:
                blocker=j
    x=x+alpha*p; path.append(x.copy())
    assert min(A@x+b)>-1e-10
    if blocker is not None: active.append(blocker)
else: raise RuntimeError("Active-set iteration limit")
full_lam=np.zeros(3); full_lam[active]=lam
candidates=[]
for k in range(3):
    for ids in combinations(range(3),k):
        W=A[list(ids)]; K=np.block([[H,-W.T],[W,np.zeros((k,k))]])
        try: sol=np.linalg.solve(K,np.r_[-g,-b[list(ids)]])
        except np.linalg.LinAlgError: continue
        if np.min(A@sol[:2]+b)>=-1e-10 and (k==0 or np.min(sol[2:])>=-1e-10): candidates.append(sol[:2])
ref=minimize(f,[.5,.5],jac=lambda z:H@z+g,method="SLSQP",
             constraints={"type":"ineq","fun":lambda z:A@z+b,"jac":lambda z:A},
             options={"ftol":1e-13,"maxiter":100})
assert ref.success and candidates
metrics={"objective":float(f(x)),"solution_error":float(np.linalg.norm(x-[1.75,.25],np.inf)),
         "primal_violation":float(max(0.,-np.min(A@x+b))),
         "stationarity":float(np.linalg.norm(H@x+g-A.T@full_lam,np.inf)),
         "complementarity":float(np.linalg.norm(full_lam*(A@x+b),np.inf)),
         "multiplier_error":float(np.linalg.norm(full_lam-[.75,0,0],np.inf)),
         "enumeration_error":float(np.linalg.norm(x-candidates[0],np.inf)),
         "slsqp_error":float(np.linalg.norm(x-ref.x,np.inf)),"working_set_iterations":iteration+1}
assert max(metrics[k] for k in metrics if k not in ("objective","working_set_iterations"))<1e-7
fig,ax=plt.subplots(1,2,figsize=(10,4.6),layout="constrained")
u=np.linspace(-.1,2.25,160); X,Y=np.meshgrid(u,u)
Z=.5*(4*X*X+2*X*Y+2*Y*Y)-8*X-3*Y
ax[0].contour(X,Y,Z,levels=[-8.4,-8.125,-7.5,-6,-4,-1],colors="#b3bcc9",linewidths=1)
ax[0].fill([0,2,0],[0,0,2],color="#dceef0",alpha=.6)
p=np.array(path); ax[0].plot(p[:,0],p[:,1],"o-",lw=2,label=tr("활성집합 이동"))
ax[0].scatter([1.75],[.25],marker="*",s=140,color="#e07945",label=tr("유일 최적점"))
ax[0].set(xlabel="x",ylabel="y",title=tr("면 위의 QP와 작업집합 교체"),xlim=(-.1,2.25),ylim=(-.1,2.25))
ax[0].legend(fontsize=9)
ax[1].bar([tr("상한 x+y≤2"),tr("하한 x≥0"),tr("하한 y≥0")],full_lam,color=["#e07945","#156f87","#7661a9"])
ax[1].set(ylabel=tr("KKT 승수"),title=tr("활성 제약이 갖는 한계 비용"),ylim=(0,1))
finish(16,fig,metrics)
