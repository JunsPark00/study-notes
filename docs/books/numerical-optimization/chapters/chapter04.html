이차 모델은 가까운 곳의 모양을 잘 보여 주지만 멀리서도 맞는 지도는 아니다. 신뢰영역 방법은 모델을 사용하는 공간을 제한하고, 실제 함수의 반응을 확인하면서 그 공간을 조절한다. 이 장에서는 좋은 곡률뿐 아니라 음의 곡률을 활용하는 방법도 살펴본다.

학습 목표와 준비

  • 모델, 반지름, 부분문제, 수락 비율을 각각 계산한다
  • Cauchy 점, dogleg, 이차원 부분공간의 차이를 설명한다
  • 구형 부분문제의 전역 최적성 조건과 어려운 경우를 이해한다
  • 정상점 수렴과 국소 뉴턴 수렴, 스케일과 노름의 영향을 구분한다

선수 지식은 테일러 근사, 대칭행렬의 고유값, 양의 정부호·준정부호다. 여기서 BkB_kBk​는 반드시 참 헤시안일 필요는 없지만 대칭인 곡률 모델로 가정한다.

4.1 먼저 믿을 범위를 정한다

현재 점 xkx_kxk​에서 만든 이차 모델을 mk(p)m_k(p)mk​(p)라고 하자. 가장 기본적인 신뢰영역 부분문제는 다음과 같다.

min⁡pmk(p)=f(xk)+gkTp+12pTBkp,subject to∥p∥2≤Δk.\begin{aligned} \min_p\quad&m_k(p)=f(x_k)+g_k^Tp+\tfrac12p^TB_kp,\\ \text{subject to}\quad&\|p\|_2\leq\Delta_k. \end{aligned}pmin​subject to​mk​(p)=f(xk​)+gkT​p+21​pTBk​p,∥p∥2​≤Δk​.​

선 탐색이 하나의 방향을 정하고 그 위에서 이동량을 고른다면, 신뢰영역은 허용된 공 안에서 방향과 길이를 함께 고른다. BkB_kBk​에 음의 고유값이 있어도 유한한 반지름 덕분에 부분문제의 최솟값은 존재한다. 모델을 무제한으로 낮추려고 멀리 달아나는 것을 막는 것이다.

실제로는 이 부분문제를 매번 아주 정확히 풀 필요가 없다. 충분한 모델 감소를 얻는 저렴한 단계가 전체 계산을 더 효율적으로 만들 수 있다. 어느 수준의 근사가 필요한지는 전역 수렴과 국소 속도에서 서로 다르게 판단한다.

4.2 Cauchy 점은 최소한의 진전 기준이다

Cauchy 점은 음의 기울기 반직선 p=−tgp=-tgp=−tg, t≥0t\geq0t≥0에서 신뢰영역 안의 가장 좋은 점이다. g≠0g\ne0g=0일 때 다음처럼 계산할 수 있다.

tC={min⁡{∥g∥2gTBg,Δ∥g∥},gTBg>0,Δ∥g∥,gTBg≤0,pC=−tCg.t_C=\begin{cases} \min\left\{\dfrac{\|g\|^2}{g^TBg},\dfrac{\Delta}{\|g\|}\right\},&g^TBg>0,\\ \dfrac{\Delta}{\|g\|},&g^TBg\leq0, \end{cases} \qquad p_C=-t_Cg.tC​=⎩⎨⎧​min{gTBg∥g∥2​,∥g∥Δ​},∥g∥Δ​,​gTBg>0,gTBg≤0,​pC​=−tC​g.

기울기 방향의 곡률이 양수면 반직선의 최소점과 경계 중 먼저 만나는 쪽을 선택한다. 곡률이 0 이하이면 모델이 그 방향으로 계속 내려가므로 경계까지 간다. g=0g=0g=0이면 이 공식의 나눗셈을 사용하지 말고 별도로 처리한다. 기울기가 0이어도 음의 곡률이 있으면 모델을 더 낮출 수 있다는 사실이 중요하다.

많은 수렴 논의는 선택한 단계가 Cauchy 감소의 일정 비율 이상을 얻는다고 가정한다. 목적함수의 하한, 적절한 매끄러움, 모델 행렬의 유계성 같은 조건도 함께 필요하다. Cauchy 점이 항상 가장 좋은 단계라는 주장이 아니라, 반복이 의미 있는 감소를 놓치지 않게 하는 기준이다.

4.3 Dogleg와 이차원 부분공간

B≻0B\succ0B≻0이면 제약 없는 뉴턴 점 pN=−B−1gp_N=-B^{-1}gpN​=−B−1g를 구할 수 있다. Dogleg는 원점에서 최급강하 반직선의 최소점 pUp_UpU​로, 다시 pNp_NpN​으로 향하는 두 선분을 사용한다. 뉴턴 점이 영역 안이면 그대로 선택하고, 밖이면 꺾인 경로와 경계의 교점을 찾는다.

작은 예로 B=(4112)B=\begin{pmatrix}4&1\\1&2\end{pmatrix}B=(41​12​), g=(1,1)Tg=(1,1)^Tg=(1,1)T, Δ=0.4\Delta=0.4Δ=0.4를 두면 pU=(−0.25,−0.25)p_U=(-0.25,-0.25)pU​=(−0.25,−0.25), pN=(−1/7,−3/7)p_N=(-1/7,-3/7)pN​=(−1/7,−3/7)이다. 앞 점은 영역 안이고 뒤 점은 밖이다. 따라서 두 점 사이의 선분에서 길이가 0.4인 점을 고르면 된다. 독립 코드에서는 약 (−0.188235,−0.352941)(-0.188235,-0.352941)(−0.188235,−0.352941)을 얻고 경계 조건을 직접 검사한다.

이차원 부분공간 방법은 두 방향이 만드는 평면 안에서 이차 모델을 더 직접적으로 최소화한다. Dogleg의 고정된 꺾인 경로보다 선택지가 넓다. 다만 거의 평행한 방향, 부정부호 곡률, 부분문제 풀이 비용 등도 고려해야 한다. 양의 정부호를 전제로 한 단순 dogleg를 부정부호 모델에 그대로 대입하지 않는다.

4.4 실제 감소와 예측 감소를 비교한다

단계 후보를 만들었다면 원래 함수를 평가한다. 수락 비율은 다음과 같다.

ρk=f(xk)−f(xk+pk)mk(0)−mk(pk).\rho_k= \frac{f(x_k)-f(x_k+p_k)}{m_k(0)-m_k(p_k)}.ρk​=mk​(0)−mk​(pk​)f(xk​)−f(xk​+pk​)​.

분모는 예측 감소이며 양수여야 비율을 정상적으로 해석할 수 있다. 분자가 음수이면 실제 비용이 올라갔다는 뜻이다. 비율이 작으면 모델의 예측이 좋지 않으므로 단계를 거절하거나 반지름을 줄인다. 비율이 충분히 좋고 경계까지 이동한 경우에는 더 큰 영역을 시도할 수 있다. 구체적인 임계값과 갱신 배율은 구현의 선택이다.

거절되면 현재 점은 유지하면서 다음 모델 시험 범위가 바뀐다. 따라서 반복 번호와 수락된 이동 횟수는 같지 않을 수 있다. 반지름이 아주 작아졌다는 사실만으로 최적이라고 선언하지 않는다. 기울기 잔차, 감소 예측, 거절 이력, 수치 정밀도를 함께 확인해야 한다.

4.5 부분문제의 전역 해를 판정하는 조건

대칭 BBB와 양수 Δ\DeltaΔ를 갖는 구형 이차 부분문제에서 전역 해 p∗p^*p∗는 어떤 λ≥0\lambda\geq0λ≥0와 함께 다음 조건으로 특징지을 수 있다.

(B+λI)p∗=−g,B+λI⪰0,∥p∗∥≤Δ,λ(Δ−∥p∗∥)=0.\begin{aligned} (B+\lambda I)p^*&=-g,\\ B+\lambda I&\succeq0,\\ \|p^*\|&\leq\Delta,\\ \lambda(\Delta-\|p^*\|)&=0. \end{aligned}(B+λI)p∗B+λI∥p∗∥λ(Δ−∥p∗∥)​=−g,⪰0,≤Δ,=0.​

양의 정부호로 이동된 행렬을 사용할 수 있는 일반적인 경우에는 p(λ)=−(B+λI)−1gp(\lambda)=-(B+\lambda I)^{-1}gp(λ)=−(B+λI)−1g를 만들고 ∥p(λ)∥=Δ\|p(\lambda)\|=\Delta∥p(λ)∥=Δ가 되도록 승수를 조정한다. 이것은 하나의 스칼라 방정식을 반복해서 푸는 접근으로 이어진다. 선형계 분해의 재사용과 승수의 안전한 구간 관리가 계산 비용에 중요하다.

하지만 역행렬이 존재하는 경우만 생각하면 중요한 해를 놓친다. 최소 고유값 방향에 기울기 성분이 없고 이동된 행렬이 특이해지는 “어려운 경우”에는 그 고유공간 성분을 추가해 경계에 도달해야 한다.

4.6 손계산: 기울기가 보지 못하는 감소 방향

4.7 국소 속도와 영역의 모양

해 근방에서 참 헤시안이 양의 정부호이고 모델이 충분히 정확하면 뉴턴 단계가 신뢰영역 안에 들어올 수 있다. 적절한 부분문제 정확도와 매끄러움 가정 아래 전체 뉴턴 단계가 수락되면서 빠른 국소 수렴을 회복한다. 전역화 장치가 있다는 사실과 빠른 국소 속도는 양립할 수 있다.

변수마다 단위가 다르면 구형 영역은 같은 물리적 의미를 갖지 않는다. ∥Dp∥2≤Δ\|Dp\|_2\leq\Delta∥Dp∥2​≤Δ처럼 스케일을 반영하면 원래 좌표에서 타원형 영역이 된다. 무한대 노름을 사용하면 상자형 영역이 된다. 반지름 숫자가 같아도 허용되는 점이 달라지고 부분문제의 해법도 달라지므로, 구형 문제의 공식을 기호만 바꾸어 적용하지 않는다.

독립 실험과 읽는 법

독립 실행 예제 내려받기는 어려운 경우의 해를 최적성 조건으로 검사하고, 촘촘한 경계 표본의 최솟값으로 추가 대조한다. 별도의 양의 정부호 예에서는 dogleg 경계 교점도 확인한다. 이 두 작은 실습은 완전한 신뢰영역 솔버가 아니다.

그림 확대

왼쪽의 두 붉은 점은 모델의 두 전역 해이며 파란 점은 Cauchy 점이다. 오른쪽은 선택한 단계 방향의 모델과 실제 함수를 비교한다. 새 실행에서 정상성 잔차는 0, 경계 노름 오차는 약 1.11×10−161.11\times10^{-16}1.11×10−16, 조밀한 경계 검사와의 모델값 차이는 약 1.64×10−101.64\times10^{-10}1.64×10−10이었다. 격자 검사는 증명이 아니므로 양의 준정부호 조건과 상보성 검사도 함께 사용했다.

#!/usr/bin/env python3
"""Original, self-contained teaching experiment. Not a production optimizer.
Run: python chapter04.py --output-dir ./output
Only NumPy, SciPy and Matplotlib are required. No network or private data.
"""
from pathlib import Path
import argparse, json, os, platform, tempfile
os.environ.setdefault("MPLCONFIGDIR", str(Path(tempfile.gettempdir()) / "optimization-learning-mpl"))
os.environ.setdefault("XDG_CACHE_HOME", str(Path(tempfile.gettempdir()) / "optimization-learning-cache"))
Path(os.environ["XDG_CACHE_HOME"]).mkdir(parents=True, exist_ok=True)
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser(description=__doc__)
parser.add_argument("--output-dir", type=Path, default=Path("."))
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"),
              Path("/usr/share/fonts/truetype/nanum/NanumGothic.ttf")]
korean = False
for font_path in font_paths:
    if font_path.exists():
        font_manager.fontManager.addfont(str(font_path))
        plt.rcParams["font.family"] = font_manager.FontProperties(fname=str(font_path)).get_name()
        korean = True
        break
plt.rcParams.update({"axes.unicode_minus": False, "font.size": 10,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f8fafc", "axes.facecolor": "#f8fafc"})
def label(ko, en):
    return ko if korean else en

def finish(chapter, fig, results):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160, bbox_inches=None)
    plt.close(fig)
    results.update({"chapter": chapter, "seed": 20261001,
                    "python": platform.python_version(), "numpy": np.__version__,
                    "scipy": scipy.__version__, "matplotlib": matplotlib.__version__,
                    "korean_labels": korean, "checks_passed": True})
    output = json.dumps(results, ensure_ascii=False, indent=2, allow_nan=False)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(output + "\n", encoding="utf-8")
    print(output)

B=np.diag([-1.,3.]); g=np.array([0.,2.]); delta=1.
def model(p): return float(g@p+.5*p@B@p)
def actual(p): return model(p)+.2*p[0]**4
lam=1.; solution=np.array([np.sqrt(.75),-.5])
cauchy=np.array([0.,-2/3])
stationarity=float(np.linalg.norm((B+lam*np.eye(2))@solution+g))
minimum_eigenvalue=float(np.linalg.eigvalsh(B+lam*np.eye(2))[0])
predicted=-model(solution); observed=-actual(solution); rho=observed/predicted
# Independent dense boundary check, plus the global optimality certificate.
theta=np.linspace(0,2*np.pi,200001)
boundary=np.stack([np.cos(theta),np.sin(theta)],axis=1)
values=boundary@g+.5*np.einsum("ni,ij,nj->n",boundary,B,boundary)
assert stationarity<1e-12 and minimum_eigenvalue>=-1e-12
assert abs(np.linalg.norm(solution)-delta)<1e-12
assert abs(model(solution)+1)<1e-12
assert abs(values.min()-model(solution))<1e-8
assert predicted>0 and abs(rho-.8875)<1e-12
assert model(solution)<model(cauchy)
# A separate positive-definite dogleg subproblem.
C=np.array([[4.,1.],[1.,2.]]); h=np.ones(2); radius=.4
pu=-(h@h)/(h@C@h)*h; pn=-np.linalg.solve(C,h)
d=pn-pu
roots=np.roots([d@d,2*pu@d,pu@pu-radius**2])
t=float(next(r.real for r in roots if abs(r.imag)<1e-12 and 0<=r.real<=1))
pdog=pu+t*d
assert abs(np.linalg.norm(pdog)-radius)<1e-12
fig,ax=plt.subplots(1,2,figsize=(10,4.5),layout="constrained")
a,b=np.meshgrid(np.linspace(-1.15,1.15,300),np.linspace(-1.15,1.15,300))
z=2*b+.5*(-a*a+3*b*b)
ax[0].contour(a,b,z,levels=[-1,-.9,-2/3,-.4,0,.5,1,2,3],colors="#a5b4fc",linewidths=.8)
theta_plot=np.linspace(0,2*np.pi,600)
ax[0].plot(np.cos(theta_plot),np.sin(theta_plot),color="#64748b",lw=1.5)
ax[0].scatter(*cauchy,color="#2563eb",s=55,label=label("Cauchy 점", "Cauchy point"),zorder=5)
ax[0].scatter([solution[0],-solution[0]],[solution[1],solution[1]],color="#e85d3f",s=65,
              label=label("두 전역 해", "Two global solutions"),zorder=5)
ax[0].set(aspect="equal",xlabel=r"$p_1$",ylabel=r"$p_2$",title=label("부정 곡률을 놓치지 않기", "Do not miss negative curvature"))
ax[0].legend(fontsize=8,loc="upper right")
t=np.linspace(0,1,300)
ax[1].plot(t,[model(v*solution) for v in t],color="#1d4ed8",lw=2,label=label("이차 모델", "Quadratic model"))
ax[1].plot(t,[actual(v*solution) for v in t],color="#0f766e",lw=2,label=label("실제 함수", "Actual function"))
ax[1].set(xlabel=label("선택한 단계의 비율 t", "Fraction of chosen step t"),ylabel=label("시작점 대비 함수값", "Change from starting value"),
          title=label("수락 비율 = 0.8875", "Acceptance ratio = 0.8875"))
ax[1].legend(fontsize=8); ax[1].grid(alpha=.2)
finish(4,fig,{"hard_case_solution":solution.tolist(),"model_value":model(solution),
              "cauchy_model_value":model(cauchy),"multiplier":lam,"stationarity_residual":stationarity,
              "shifted_minimum_eigenvalue":minimum_eigenvalue,"boundary_norm_error":abs(float(np.linalg.norm(solution))-1),
              "dense_boundary_value_gap":float(values.min()-model(solution)),"actual_reduction":observed,
              "predicted_reduction":predicted,"acceptance_ratio":rho,"dogleg_step":pdog.tolist(),
              "dogleg_boundary_error":abs(float(np.linalg.norm(pdog))-radius)})
