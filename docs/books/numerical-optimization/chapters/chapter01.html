최적화의 출발점은 알고리즘 이름이 아니라 “내가 바꿀 수 있는 것은 무엇이고, 좋은 선택은 무엇인가?”라는 질문이다. 이 장에서는 작은 에너지 구매 계획을 직접 정식화하고, 해의 의미와 검증 방법을 연결한다. 비용을 최소화하는 코드는 짧지만, 잘못된 단위나 빠진 제약을 코드가 알아서 고쳐 주지는 않는다.

학습 목표와 준비

  • 변수, 데이터, 목적함수, 허용 집합을 구분하고 단위를 적을 수 있다
  • 연속·이산, 제약·무제약, 국소·전역이라는 분류를 서로 혼동하지 않는다
  • 볼록성, 해의 존재, 해의 유일성이 각각 다른 질문임을 설명한다
  • 솔버의 성공 표시를 실행 가능성 검사와 독립 계산으로 보완한다

선수 지식은 일차함수, 부등식, 평면 좌표 정도면 충분하다. 벡터 표기는 여러 결정을 한꺼번에 묶는 약속으로 읽으면 된다.

1.1 선택 가능한 것과 평가하는 것을 분리한다

변수 xxx는 우리가 선택할 수 있는 값이다. 가격, 수요, 장치 효율처럼 이미 주어진 값은 데이터다. 목적함수 f(x)f(x)f(x)는 선택의 좋고 나쁨을 하나의 수로 비교하며, 제약은 선택해도 되는 범위를 제한한다. 이 자료의 일반 부등식 표기는 교재와 같은 ci(x)≥0c_i(x)\geq0ci​(x)≥0을 사용한다.

min⁡x∈Rnf(x)subject toci(x)=0  (i∈E),ci(x)≥0  (i∈I).\min_{x\in\mathbb R^n} f(x) \quad\text{subject to}\quad c_i(x)=0\;(i\in\mathcal E),\qquad c_i(x)\geq0\;(i\in\mathcal I).x∈Rnmin​f(x)subject toci​(x)=0(i∈E),ci​(x)≥0(i∈I).

모든 제약을 만족하는 점들의 집합을 실행 가능 집합이라고 부른다. 어느 점도 제약을 동시에 만족하지 못하면 문제는 실행 불가능하다. 허용되는 점은 있어도 비용을 끝없이 낮출 수 있다면 최솟값이 유한하지 않다. 유한한 하한이 있어도 그 값을 달성하는 점이 없을 수 있다. 예를 들어 양수 xxx만 허용하면서 xxx를 최소화하면 하한은 0이지만 허용되는 최적점은 없다.

문장을 식으로 옮길 때에는 각 항의 단위부터 맞춘다. 에너지 수요와 순간 전력을 바로 더할 수 없고, 구매량과 실제 공급량 사이에 손실이 있다면 그 차이를 식에 넣어야 한다. 제약 하나가 빠진 모델의 정확한 해는 원래 의사결정의 정확한 답이 아니다.

1.2 새 예제: 저녁 전력 구매를 나누기

작은 건물의 저녁 에너지 수요를 6 kWh라고 하자. 미리 확보한 태양광 에너지가 저녁에 1 kWh를 공급하므로 남은 5 kWh를 두 방법으로 조달한다. 저가 시간에 충전하는 양 xxx는 최대 4 kWh이고, 그중 80%가 저녁에 전달된다. 저녁에 직접 구매하는 양 yyy는 최대 5 kWh다. 가격은 각각 kWh당 0.18, 0.40이라는 가상 화폐 단위로 둔다.

min⁡x,y0.18x+0.40ysubject to0.8x+y≥5,0≤x≤4,0≤y≤5.\begin{aligned} \min_{x,y}\quad &0.18x+0.40y\\ \text{subject to}\quad &0.8x+y\geq5,\\ &0\leq x\leq4,\qquad0\leq y\leq5. \end{aligned}x,ymin​subject to​0.18x+0.40y0.8x+y≥5,0≤x≤4,0≤y≤5.​

이 수치는 실제 요금이나 배터리 사양이 아니라 설명을 위해 새로 정한 값이다. 시간대별 전력 한도, 충전 상태의 시간 변화, 배터리 열화는 이 작은 모델에 포함하지 않았다. 단순한 모델일수록 무엇을 생략했는지도 분명히 해야 한다.

두 가격이 모두 양수이므로 최적점에서 필요량보다 더 공급할 이유가 없다. 따라서 수요 경계에서 y=5−0.8xy=5-0.8xy=5−0.8x를 대입해 두 변수 문제를 한 변수 문제로 줄일 수 있다.

0.18x+0.40(5−0.8x)=2−0.14x.0.18x+0.40(5-0.8x)=2-0.14x.0.18x+0.40(5−0.8x)=2−0.14x.

xxx가 1 증가할 때 비용이 0.14 감소하므로 가능한 가장 큰 x=4x=4x=4를 고른다. 그러면 y=1.8y=1.8y=1.8이고 비용은 1.44다. 공급량은 0.8×4+1.8=50.8\times4+1.8=50.8×4+1.8=5여서 제약도 맞는다. 이 계산은 솔버의 내부 알고리즘을 사용하지 않는 독립적인 검산이다.

수송·배분 문제도 이와 같은 모델링 습관으로 읽을 수 있다. 보내는 양을 변수로 정하고, 공급량에는 상한을, 필요한 양에는 하한이나 등식을 놓는다. 원래 수송 예제의 표나 계수를 옮기지 않아도 “무엇이 이동하며 어느 자원이 보존되는가”라는 핵심 질문은 다른 문제에 적용된다.

1.3 연속과 이산: 반올림은 별도의 결정이다

충전량을 임의의 실수로 정할 수 있다면 연속 최적화다. 충전 장치를 몇 대 설치할지, 어느 시간에 켤지를 정하면 정수 또는 이진 변수가 등장한다. 같은 목적식을 써도 허용 집합이 달라지므로 문제의 성질이 달라진다.

정수 제약을 풀어서 실수까지 허용한 문제를 연속 완화라고 한다. 최소화 문제에서는 선택지가 늘어나므로 완화의 최적 비용은 원래 정수 문제의 최적 비용보다 클 수 없다. 그러나 완화 해를 반올림하면 수요 부족이나 자원 초과가 생길 수 있다. 반올림한 뒤 제약을 다시 검사하는 것은 최소한의 절차이며, 검사에 통과해도 최적이라는 뜻은 아니다.

앞 예제에서 구매 단위를 정수 kWh로 강제하면 (4,1.8)(4,1.8)(4,1.8)은 더 이상 후보가 아니다. 가장 가까운 실행 가능 정수 선택의 비용은 연속 최적 비용과 비교해야 한다. 연속 모델이 현실적으로 적절한지는 계산 결과가 아니라 구매 규칙을 보고 결정한다.

1.4 제약, 국소성, 불확실성은 다른 축이다

무제약 문제는 모든 실수 벡터를 후보로 둔다. 제약이 있는 문제는 경계에서도 최적점이 생길 수 있어, 무제약의 기울기 0 조건을 그대로 적용하면 안 된다. 제약 위반에 벌점을 매겨 목적함수에 더하는 방법도 있지만, 유한한 벌점 계수에서 나온 해가 원래 제약을 정확히 지킨다는 보장은 별도로 확인해야 한다.

국소 최소는 충분히 작은 이웃에서 더 나은 점이 없다는 뜻이다. 전역 최소는 모든 실행 가능 점과 비교한다. 여러 골짜기가 있는 함수에서는 시작점에 따라 다른 국소 최소에 도달할 수 있다. 기울기가 작다는 관측은 가까운 곳의 일차 변화가 작다는 정보이지, 멀리 떨어진 더 깊은 골짜기가 없다는 증거는 아니다.

데이터가 고정되어 있으면 결정론적 모델이다. 수요나 가격을 확률변수로 취급하면 불확실성을 포함한 모델을 세워야 한다. 예를 들어 시나리오 jjj의 손실을 L(x,ξj)L(x,\xi_j)L(x,ξj​), 발생 확률을 pjp_jpj​로 정하면 기대 손실을 다음처럼 쓸 수 있다.

min⁡x∑j=1mpjL(x,ξj),pj≥0,∑j=1mpj=1.\min_x\sum_{j=1}^{m}p_jL(x,\xi_j), \qquad p_j\geq0,\quad\sum_{j=1}^{m}p_j=1.xmin​j=1∑m​pj​L(x,ξj​),pj​≥0,j=1∑m​pj​=1.

평균 수요만 넣고 최적화하는 것과 시나리오별 손실의 평균을 최소화하는 것은 일반적으로 다르다. 부족분에만 비싼 추가 비용이 붙으면 그 차이가 특히 중요하다. 한편 무작위 초기값을 사용하는 알고리즘이 곧 확률적 데이터 모델인 것은 아니다. 무엇이 불확실한지와 계산에 난수를 쓰는지를 구분하자.

1.5 볼록성은 무엇을 보장할까

집합이 볼록하다는 것은 그 안의 두 점을 잇는 선분 전체가 집합 안에 있다는 뜻이다. 함수의 볼록성은 선분 위의 함수값이 양 끝의 값으로 만든 직선보다 높지 않다는 뜻이다.

f(tx+(1−t)y)≤tf(x)+(1−t)f(y),0≤t≤1.f(tx+(1-t)y)\leq t f(x)+(1-t)f(y), \qquad0\leq t\leq1.f(tx+(1−t)y)≤tf(x)+(1−t)f(y),0≤t≤1.

볼록 집합 위의 볼록 함수에서는 국소 최소가 전역 최소다. 엄격 볼록성은 최적점이 존재한다면 그 유일성을 준다. 존재 자체는 별도 조건이다. 연속 함수가 비어 있지 않은 닫히고 유계인 집합 위에 정의되어 있다면 최솟값을 달성한다는 조건을 자주 이용한다.

부등식을 ci≥0c_i\geq0ci​≥0로 쓰는 경우에는 cic_ici​가 오목하면 그 제약의 허용 집합이 볼록이다. 부호 관례를 반대로 바꾸면 함수의 볼록·오목 조건도 함께 바뀐다. 앞의 구매 문제는 목적과 제약이 모두 선형이고 허용 집합이 닫히고 유계이므로 최적점의 존재와 전역성을 설명하기 쉽다.

1.6 실행 결과를 읽는 순서

알고리즘은 반복점, 평가 횟수, 잔차, 종료 사유를 남겨야 한다. 정확도를 높일수록 계산이 비싸질 수 있고, 한 문제에서 빠른 방법이 나쁜 초기값에도 강한 것은 아니다. 강건성·효율성·정확성 중 무엇이 중요한지 용도에 맞춰 정한다.

독립 실행 예제 내려받기는 SciPy의 선형계획 솔버를 호출한 뒤, 손으로 얻은 해 및 수요 경계의 비용과 비교한다. NumPy·SciPy·Matplotlib만 사용하며 별도 데이터나 다른 장의 코드를 읽지 않는다. 실행하면 그림과 검사 결과 JSON을 지정한 출력 폴더에 만든다.

그림 확대

그림의 초록 영역은 공급량과 구매 상한을 모두 만족한다. 왼쪽의 비용 등고선과 오른쪽의 감소하는 직선은 서로 다른 방식으로 같은 최적점을 설명한다. 새 실행에서 비용 1.44, 최대 제약 위반 0, 해의 최대 성분 오차 약 2.22×10−162.22\times10^{-16}2.22×10−16을 확인했다. 마지막 자릿수는 실행 환경에 따라 달라질 수 있다.

자주 하는 실수

  • 충전 효율 0.8을 비용에도 곱한다: 비용은 구매량에, 효율은 공급량에 적용한다
  • 제약 부호를 바꾸고 설명은 그대로 둔다: 사용하는 솔버의 부등식 형식까지 확인한다
  • 성공 메시지만 기록한다: 실행 가능성과 비교 기준을 별도로 남긴다
  • 이 사례의 전역성을 모든 비선형 문제에 옮긴다: 선형성과 볼록성이라는 근거를 먼저 확인한다

#!/usr/bin/env python3
"""Original, self-contained teaching experiment. Not a production optimizer.
Run: python chapter01.py --output-dir ./output
Only NumPy, SciPy and Matplotlib are required. No network or private data.
"""
from pathlib import Path
import argparse, json, os, platform, tempfile
os.environ.setdefault("MPLCONFIGDIR", str(Path(tempfile.gettempdir()) / "optimization-learning-mpl"))
os.environ.setdefault("XDG_CACHE_HOME", str(Path(tempfile.gettempdir()) / "optimization-learning-cache"))
Path(os.environ["XDG_CACHE_HOME"]).mkdir(parents=True, exist_ok=True)
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser(description=__doc__)
parser.add_argument("--output-dir", type=Path, default=Path("."))
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"),
              Path("/usr/share/fonts/truetype/nanum/NanumGothic.ttf")]
korean = False
for font_path in font_paths:
    if font_path.exists():
        font_manager.fontManager.addfont(str(font_path))
        plt.rcParams["font.family"] = font_manager.FontProperties(fname=str(font_path)).get_name()
        korean = True
        break
plt.rcParams.update({"axes.unicode_minus": False, "font.size": 10,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f8fafc", "axes.facecolor": "#f8fafc"})
def label(ko, en):
    return ko if korean else en

def finish(chapter, fig, results):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160, bbox_inches=None)
    plt.close(fig)
    results.update({"chapter": chapter, "seed": 20261001,
                    "python": platform.python_version(), "numpy": np.__version__,
                    "scipy": scipy.__version__, "matplotlib": matplotlib.__version__,
                    "korean_labels": korean, "checks_passed": True})
    output = json.dumps(results, ensure_ascii=False, indent=2, allow_nan=False)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(output + "\n", encoding="utf-8")
    print(output)

from scipy.optimize import linprog
# Evening demand is 6 kWh; 1 kWh is supplied by previously stored solar.
# x = off-peak charge, y = peak-time grid purchase, both in kWh.
c = np.array([0.18, 0.40])
A = np.array([[-0.8, -1.0]])
b = np.array([-5.0])
result = linprog(c, A_ub=A, b_ub=b, bounds=[(0, 4), (0, 5)], method="highs")
assert result.success, result.message
reference = np.array([4.0, 1.8])
violation = max(0.0, float(np.max(A @ result.x - b)),
                float(np.max(-result.x)), float(result.x[0]-4), float(result.x[1]-5))
assert np.linalg.norm(result.x-reference, np.inf) < 1e-9
assert violation < 1e-9 and abs(result.fun-1.44) < 1e-9
# Independent 1-D elimination and a finite grid check, not another LP call.
xs = np.linspace(0, 4, 1001)
ys = 5-0.8*xs
costs = .18*xs + .4*ys
assert np.argmin(costs) == len(xs)-1
fig, ax = plt.subplots(1, 2, figsize=(10, 4.5), layout="constrained")
grid_x, grid_y = np.meshgrid(np.linspace(0, 4, 200), np.linspace(0, 5, 200))
cont = ax[0].contour(grid_x, grid_y, .18*grid_x+.4*grid_y, levels=np.arange(.4, 3, .4),
                     colors="#94a3b8", linewidths=.8)
ax[0].clabel(cont, fontsize=8)
ax[0].fill_between(xs, ys, 5, color="#99e4d5", alpha=.7, label=label("실행 가능 영역", "Feasible set"))
ax[0].plot(xs, ys, color="#0f766e", lw=2)
ax[0].scatter(*result.x, s=70, color="#e85d3f", zorder=5, label=label("최적점 (4, 1.8)", "Optimum (4, 1.8)"))
ax[0].set(xlim=(-.1, 4.2), ylim=(-.1, 5.2), xlabel=label("저가 시간 충전 x (kWh)", "Off-peak charge x (kWh)"),
          ylabel=label("고가 시간 구매 y (kWh)", "Peak purchase y (kWh)"), title=label("제약이 허용하는 선택", "Choices allowed by constraints"))
ax[0].legend(loc="lower left", fontsize=8)
ax[1].plot(xs, costs, color="#1d4ed8", lw=2.5)
ax[1].scatter([4], [1.44], color="#e85d3f", s=65)
ax[1].annotate("2 - 0.14 x", xy=(1.8, 1.748), xytext=(.4, 1.56),
                arrowprops={"arrowstyle":"->", "color":"#64748b"}, fontsize=11)
ax[1].set(xlabel=label("저가 시간 충전 x (kWh)", "Off-peak charge x (kWh)"),
          ylabel=label("비용 (가상 화폐 단위)", "Cost (illustrative units)"),
          title=label("수요 경계 위에서 독립 검산", "Independent check on demand boundary"))
ax[1].grid(alpha=.2)
finish(1, fig, {"x": result.x.tolist(), "objective": float(result.fun),
                "max_constraint_violation": violation,
                "analytic_solution_error_inf": float(np.linalg.norm(result.x-reference, np.inf)),
                "boundary_cost_slope": -0.14})
