헤시안을 정확히 계산하거나 분해하는 일이 비쌀 때, 이미 계산한 기울기의 변화가 곡률의 단서를 제공한다. 준뉴턴 방법은 이 단서를 저장하여 다음 방향을 개선한다. 핵심은 헤시안을 아무 행렬로 대체하는 것이 아니라, 새로운 관측과 기존 구조를 함께 만족시키는 갱신을 설계하는 데 있다.

학습 목표와 준비

  • Secant 조건이 어떤 방향의 곡률 정보를 담는지 설명한다
  • 헤시안 근사 BBB와 역헤시안 근사 HHH의 공식을 구분한다
  • BFGS의 양정성, SR1의 부정 곡률, Broyden 계열의 차이를 이해한다
  • 작은 분모를 처리하고 수렴 주장에 필요한 가정을 확인한다

선수 지식은 선 탐색, 양의 정부호 행렬, 외적, 선형계 풀이이다. 준뉴턴은 이전 단계의 계산을 재활용하므로 잘못된 기울기나 매우 작은 이동이 이후 여러 단계에 영향을 줄 수 있다.

6.1 이동과 기울기 차이가 주는 정보

연속한 두 점의 이동과 기울기 변화를 다음처럼 정의한다.

sk=xk+1−xk,yk=gk+1−gk.s_k=x_{k+1}-x_k,\qquad y_k=g_{k+1}-g_k.sk​=xk+1​−xk​,yk​=gk+1​−gk​.

매끄러운 함수에서는 기울기 변화가 이동 경로의 헤시안 평균과 연결된다.

yk=(∫01∇2f(xk+tsk) dt)sk.y_k=\left(\int_0^1\nabla^2f(x_k+t s_k)\,dt\right)s_k.yk​=(∫01​∇2f(xk​+tsk​)dt)sk​.

따라서 새 헤시안 근사에 Bk+1sk=ykB_{k+1}s_k=y_kBk+1​sk​=yk​를 요구하는 것은 최근에 관측한 방향의 곡률을 맞추는 일이다. 역헤시안을 저장한다면 조건은 Hk+1yk=skH_{k+1}y_k=s_kHk+1​yk​=sk​가 된다. 이를 secant 조건이라고 부른다.

벡터 한 쌍은 행렬 전체를 결정하지 않는다. 예를 들어 s=(1,0)Ts=(1,0)^Ts=(1,0)T, y=(4,1)Ty=(4,1)^Ty=(4,1)T이면 대칭 행렬 BBB의 첫 번째 열은 정해지지만 오른쪽 아래 성분은 남는다. 같은 secant 조건을 만족하는 여러 근사가 존재하므로, 대칭성·양정성·기존 행렬에서의 변화량 같은 기준이 추가로 필요하다.

6.2 BFGS는 곡률 조건을 활용한다

헤시안 형태의 BFGS 갱신은 다음과 같다.

Bk+1=Bk−BkskskTBkskTBksk+ykykTykTsk.B_{k+1}=B_k- \frac{B_ks_ks_k^TB_k}{s_k^TB_ks_k} +\frac{y_ky_k^T}{y_k^Ts_k}.Bk+1​=Bk​−skT​Bk​sk​Bk​sk​skT​Bk​​+ykT​sk​yk​ykT​​.

Bk≻0B_k\succ0Bk​≻0이고 ykTsk>0y_k^Ts_k>0ykT​sk​>0이면 새 행렬도 양의 정부호다. 이 성질은 다음 방향을 하강 방향으로 만드는 데 중요하다. 역헤시안 형태는 ρk=1/(ykTsk)\rho_k=1/(y_k^Ts_k)ρk​=1/(ykT​sk​)를 사용한다.

Hk+1=(I−ρkskykT)Hk(I−ρkykskT)+ρkskskT.H_{k+1}=(I-\rho_ks_ky_k^T)H_k(I-\rho_ky_ks_k^T) +\rho_ks_ks_k^T.Hk+1​=(I−ρk​sk​ykT​)Hk​(I−ρk​yk​skT​)+ρk​sk​skT​.

방향은 pk=−Hkgkp_k=-H_kg_kpk​=−Hk​gk​로 얻는다. 이 표현에서는 매번 행렬 역을 구할 필요가 없다. 실제 구현은 외적과 행렬·벡터 곱을 이용해 밀집 갱신을 보통 O(n2)O(n^2)O(n2) 비용으로 수행한다. 작은 학습 코드에서 위 식을 그대로 여러 행렬 곱으로 작성한 것과, 최적화된 구현의 연산량은 구분해야 한다.

Wolfe 곡률 조건이 왜 등장하는지도 계산할 수 있다. sk=αkpks_k=\alpha_kp_ksk​=αk​pk​이고 gkTpk<0g_k^Tp_k<0gkT​pk​<0이면 다음 관계가 성립한다.

ykTsk=αk(gk+1Tpk−gkTpk)≥αk(c2−1)gkTpk>0.y_k^Ts_k =\alpha_k(g_{k+1}^Tp_k-g_k^Tp_k) \geq\alpha_k(c_2-1)g_k^Tp_k>0.ykT​sk​=αk​(gk+1T​pk​−gkT​pk​)≥αk​(c2​−1)gkT​pk​>0.

따라서 Wolfe 탐색은 BFGS 갱신에 필요한 양의 곡률을 제공한다. 그러나 실수 연산에서는 양수인 것만으로 충분하지 않을 수 있다. 아주 작은 분모, 부정확한 기울기, 거의 움직이지 않은 단계에는 상대 크기 검사와 갱신 생략·감쇠 같은 보호가 필요하다.

6.4 SR1은 양정성을 강제하지 않는다

SR1은 잔차 벡터 vk=yk−Bkskv_k=y_k-B_ks_kvk​=yk​−Bk​sk​에 대한 하나의 대칭 외적 보정을 사용한다.

Bk+1=Bk+vkvkTvkTsk.B_{k+1}=B_k+ \frac{v_kv_k^T}{v_k^Ts_k}.Bk+1​=Bk​+vkT​sk​vk​vkT​​.

분모가 적절하면 secant 조건을 만족하지만 양의 정부호를 보존할 필요는 없다. 예를 들어 B0=IB_0=IB0​=I, s=(1,0)Ts=(1,0)^Ts=(1,0)T, y=(−2,0.5)Ty=(-2,0.5)^Ty=(−2,0.5)T이면 v=(−3,0.5)Tv=(-3,0.5)^Tv=(−3,0.5)T이고 분모는 −3-3−3이다. 새 행렬은 음의 고유값을 갖는다. 이는 데이터가 알려 준 음의 곡률을 표현한 것이며 갱신이 반드시 잘못되었다는 뜻은 아니다.

부정부호 근사를 선 탐색 뉴턴 방향에 바로 사용하면 하강성이 깨질 수 있으므로 SR1은 신뢰영역과 자연스럽게 결합된다. 한편 분모가 거의 0이면 거대한 보정이 생긴다. 흔히 다음과 같은 상대 기준으로 갱신 여부를 판단한다.

∣vkTsk∣≥η∥vk∥ ∥sk∥,0<η≪1.|v_k^Ts_k|\geq\eta\|v_k\|\,\|s_k\|, \qquad0<\eta\ll1.∣vkT​sk​∣≥η∥vk​∥∥sk​∥,0<η≪1.

vk=0v_k=0vk​=0이면 이미 secant 조건을 만족하므로 보정할 필요가 없다. vk≠0v_k\ne0vk​=0인데 내적만 매우 작으면 안전하게 생략할 수 있지만, 이때는 새 secant 오차가 남는다. 분모가 작다고 무조건 작은 상수로 바꿔 나누는 방식은 원래 갱신의 의미를 바꾼다.

6.5 Broyden 계열: 같은 관측을 다르게 반영하기

BFGS와 DFP는 같은 secant 조건과 대칭성을 만족하더라도 일반적으로 다른 행렬을 만든다. 역헤시안 형태의 DFP는 다음 식이다.

Hk+1DFP=Hk−HkykykTHkykTHkyk+skskTykTsk.H_{k+1}^{DFP}=H_k- \frac{H_ky_ky_k^TH_k}{y_k^TH_ky_k} +\frac{s_ks_k^T}{y_k^Ts_k}.Hk+1DFP​=Hk​−ykT​Hk​yk​Hk​yk​ykT​Hk​​+ykT​sk​sk​skT​​.

헤시안 형태의 Broyden 계열을 쓰면 BFGS에 추가 외적을 더하는 방식으로 표현할 수 있다. 아래에서는 같은 현재 B,s,yB,s,yB,s,y를 사용한다.

Bϕ+=BBFGS++ϕ(sTBs)vvT,v=yyTs−BssTBs.\begin{aligned} B_{\phi}^{+}&=B_{BFGS}^{+}+\phi(s^TBs)vv^T,\\ v&=\frac{y}{y^Ts}-\frac{Bs}{s^TBs}. \end{aligned}Bϕ+​v​=BBFGS+​+ϕ(sTBs)vvT,=yTsy​−sTBsBs​.​

vTs=0v^Ts=0vTs=0이므로 추가 항은 secant 조건을 바꾸지 않는다. 이 표현에서 ϕ=0\phi=0ϕ=0은 BFGS, ϕ=1\phi=1ϕ=1은 DFP의 헤시안 형태에 해당한다. 허용하는 매개변수 범위와 양정성 조건을 함께 보아야 하며, 헤시안 표현의 매개변수를 역헤시안 표현에 그대로 대입해 같은 갱신이라고 가정하지 않는다.

손계산의 동일한 H0,s,yH_0,s,yH0​,s,y로 역형 BFGS와 DFP를 비교하면 둘 다 Hy=sHy=sHy=s를 만족하지만 행렬의 Frobenius 노름 차이는 0.0625다. 단일 secant 잔차가 0이라는 사실은 두 방법이 다음의 모든 방향에서도 똑같이 행동한다는 뜻이 아니다.

6.6 수렴을 말할 때 필요한 것

균일하게 양의 곡률이 유지되는 매끄러운 문제, 적절한 Wolfe 탐색, 양의 정부호 초기 근사 같은 조건 아래 BFGS의 수렴을 분석할 수 있다. 일반 비볼록 함수에서도 같은 결론이 조건 없이 성립한다고 말하면 안 된다. 해 근방의 헤시안 정칙성, 갱신의 정확성, 단계 길이가 전체 단계에 접근하는 성질은 초선형 수렴을 논의할 때 중요하다.

초선형은 오차 비율 ∥ek+1∥/∥ek∥\|e_{k+1}\|/\|e_k\|∥ek+1​∥/∥ek​∥이 0으로 간다는 뜻이다. 그보다 강한 이차 수렴과 같은 말이 아니다. 행렬 전체가 정확해지는 것 대신 실제 단계 방향에서의 근사 오차가 충분히 줄어드는 조건을 사용할 수 있다.

∥(Bk−∇2f(x∗))sk∥∥sk∥⟶0.\frac{\|(B_k-\nabla^2f(x^*))s_k\|}{\|s_k\|}\longrightarrow0.∥sk​∥∥(Bk​−∇2f(x∗))sk​∥​⟶0.

이 식 하나만 떼어 쓰는 것이 아니라 반복점의 수렴과 해의 정칙성 등 필요한 가정과 함께 읽는다. SR1에서는 갱신이 얼마나 자주 생략되는지, 서로 충분히 다른 방향의 정보가 들어오는지도 중요하다. 두 번의 작은 실험으로 일반 정리를 입증할 수는 없다.

그림 확대

왼쪽은 BFGS의 두 단계와 최급강하 경로다. 오른쪽은 원점에 옮겨 그린 dTBkd=1d^TB_kd=1dTBk​d=1 등고선이다. 좌표 위치의 이동 대신 모델 형상의 변화를 비교하기 위해 중심을 맞췄다. 이번 이차함수에서는 두 번의 독립 방향 정보와 정확 선 탐색으로 최종 근사가 참 곡률과 수치 오차 범위에서 일치한다.

  • SR1의 음의 고유값을 구현 오류로 단정하지 않는다
  1. 손계산에서 y=(−4,1)Ty=(-4,1)^Ty=(−4,1)T로 바꾸면 BFGS 양정성 보장이 유지되는가? 힌트: sTy=−4s^Ty=-4sTy=−4이므로 핵심 가정이 깨진다.
  2. B=IB=IB=I, s=(1,0)Ts=(1,0)^Ts=(1,0)T, y=(1,1)Ty=(1,1)^Ty=(1,1)T에서 SR1을 바로 적용할 수 있는가? 힌트: v=(0,1)Tv=(0,1)^Tv=(0,1)T여서 분모가 0이다. secant 정보가 없어졌다는 뜻은 아니지만 이 rank-one 공식은 사용할 수 없다.
  3. 오른쪽 등고선이 참 헤시안과 같다고 해서 일반 비선형 함수도 두 번 만에 끝날까? 힌트: 이번에는 헤시안이 어디서나 같은 두 차원 이차함수다. 위치마다 곡률이 달라지면 같은 설명을 쓸 수 없다.

Q=np.array([[3.,.8],[.8,1.5]]); b=np.array([1.,-2.]); star=np.linalg.solve(Q,b)
def f(x): return .5*float(x@Q@x)-float(b@x)
def grad(x): return Q@x-b
H=np.eye(2); x=np.array([-2.,2.]); path=[x.copy()]; inverse_models=[H.copy()]
secant=[]; minimum_eigenvalues=[]
for _ in range(5):
    g=grad(x)
    if np.linalg.norm(g)<1e-11: break
    p=-H@g; assert float(g@p)<0
    alpha=-float(g@p)/float(p@Q@p)
    new=x+alpha*p; s=new-x; y=grad(new)-g; sy=float(s@y)
    assert sy>1e-12*np.linalg.norm(s)*np.linalg.norm(y)
    rho=1/sy; V=np.eye(2)-rho*np.outer(s,y)
    H=V@H@V.T+rho*np.outer(s,s)
    H=(H+H.T)/2
    secant.append(float(np.linalg.norm(H@y-s)))
    minimum_eigenvalues.append(float(np.linalg.eigvalsh(H)[0]))
    x=new; path.append(x.copy()); inverse_models.append(H.copy())
assert len(path)-1==2 and np.linalg.norm(x-star)<1e-10
assert max(secant)<1e-10 and min(minimum_eigenvalues)>0
assert np.linalg.norm(H-np.linalg.inv(Q))<1e-10
# Independent one-update BFGS/DFP and indefinite SR1 checks.
s=np.array([1.,0.]); y=np.array([4.,1.]); initial=np.eye(2)
rho=1/float(s@y); V=np.eye(2)-rho*np.outer(s,y)
hb=V@initial@V.T+rho*np.outer(s,s)
hd=initial-np.outer(y,y)/float(y@y)+np.outer(s,s)/float(s@y)
assert np.linalg.norm(hb@y-s)<1e-12 and np.linalg.norm(hd@y-s)<1e-12
ys=np.array([-2.,.5]); v=ys-initial@s; denom=float(v@s)
assert abs(denom)>=1e-8*np.linalg.norm(v)*np.linalg.norm(s)
bs=initial+np.outer(v,v)/denom
assert np.linalg.norm(bs@s-ys)<1e-12 and np.linalg.eigvalsh(bs)[0]<0
path=np.array(path)
sd=[path[0].copy()]
for _ in range(30):
    gg=grad(sd[-1])
    if np.linalg.norm(gg)<1e-10: break
    aa=float(gg@gg)/float(gg@Q@gg); sd.append(sd[-1]-aa*gg)
sd=np.array(sd)
fig,ax=plt.subplots(1,2,figsize=(10,4.5),layout="constrained")
u,vv=np.meshgrid(np.linspace(-2.5,2.6,300),np.linspace(-2.8,2.5,300))
du=u-star[0]; dv=vv-star[1]
z=.5*(Q[0,0]*du**2+2*Q[0,1]*du*dv+Q[1,1]*dv**2)
ax[0].contour(u,vv,z,levels=[.05,.2,.5,1,2,4,8,16],colors="#a5b4fc",linewidths=.8)
ax[0].plot(sd[:,0],sd[:,1],"o-",color="#94a3b8",ms=3,label=label("최급강하", "Steepest descent"))
ax[0].plot(path[:,0],path[:,1],"o-",color="#0f766e",ms=5,label="BFGS")
ax[0].scatter(*star,marker="*",s=90,color="#e85d3f",zorder=5)
ax[0].set(xlabel=r"$x_1$",ylabel=r"$x_2$",aspect="equal",title=label("곡률 정보를 기억하는 두 단계", "Two steps that remember curvature"))
ax[0].legend(fontsize=8)
angles=np.linspace(0,2*np.pi,500); unit=np.stack([np.cos(angles),np.sin(angles)])
for k,hh in enumerate(inverse_models):
    vals,vecs=np.linalg.eigh(hh)
    points=vecs@np.diag(np.sqrt(vals))@unit
    ax[1].plot(points[0],points[1],lw=2,label=f"B{k}" + (label(" (정확)", " (exact)") if k==2 else ""))
ax[1].set(xlabel=r"$d_1$",ylabel=r"$d_2$",aspect="equal",title=label("단위 모델 등고선의 변화", "Changing unit model contours"))
ax[1].legend(fontsize=8); ax[1].grid(alpha=.2)

              "gradient_norm":float(np.linalg.norm(grad(x))),"max_inverse_secant_residual":max(secant),

              "worked_bfgs_inverse":hb.tolist(),"bfgs_dfp_matrix_difference":float(np.linalg.norm(hb-hd)),
