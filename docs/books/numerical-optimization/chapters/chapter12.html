제약이 있는 최소점에서는 목적함수의 기울기가 0일 필요가 없다. 비용을 낮추는 방향이 있어도 그 방향으로 움직이면 허용 집합을 벗어날 수 있기 때문이다. 제약 최적화 이론은 이 기하학을 기울기, 승수, 곡률로 표현한다. 이 장은 KKT 조건을 암기하는 대신 언제 필요한 조건이며 언제 충분한지, 그 부호가 어떤 의미인지 확인하는 데 초점을 둔다.

학습 목표

  • 실제 가능한 방향과 제약을 선형화해 얻은 방향을 구별한다
  • 제약 자격이 KKT 필요조건에서 하는 역할을 설명한다
  • 정상성·실행 가능성·쌍대 가능성·상보성을 일관된 부호로 검사한다
  • 접방향의 이차 곡률, 승수 민감도, 쌍대 하한을 연결한다

이 페이지의 부호 관례

다음 형식을 사용한다. 등식과 부등식의 인덱스 집합을 각각 E\mathcal EE, I\mathcal II라 쓴다.

실행 가능한 점에서 ci(x)=0c_i(x)=0ci​(x)=0인 부등식은 활성이고 ci(x)>0c_i(x)>0ci​(x)>0이면 비활성이다. 비활성 제약은 충분히 작은 근방에서 이동을 즉시 막지는 않는다. 그러나 큰 스텝 뒤에는 활성 집합이 바뀔 수 있으므로 “현재 비활성”과 “문제에서 삭제해도 됨”은 다르다.

접선뿔과 선형화된 방향

실제 허용 집합을 Ω\OmegaΩ라 하자. 접선뿔은 xxx로 접근하는 실행 가능 점들의 작은 이동을 확대해 얻을 수 있는 극한 방향들의 집합이다. 매끄러운 곡면에서는 접공간과 친숙하게 연결되지만, 모서리나 경계에서는 한쪽 방향만 허용할 수 있으므로 일반적으로 공간이 아니라 뿔이다.

제약을 일차로 근사하면 다음 선형화뿔을 얻는다.

Tlin(x)={d:∇ci(x)Td=0 (i∈E),∇ci(x)Td≥0 (i∈A(x)∩I)}.\mathcal T_{\rm lin}(x)=\{d:\nabla c_i(x)^Td=0\ (i\in\mathcal E),\quad \nabla c_i(x)^Td\geq0\ (i\in\mathcal A(x)\cap\mathcal I)\}.Tlin​(x)={d:∇ci​(x)Td=0 (i∈E),∇ci​(x)Td≥0 (i∈A(x)∩I)}.

A(x)\mathcal A(x)A(x)는 활성 제약을 나타낸다. 실제 가능한 접방향은 매끄러운 제약의 일차식을 만족하지만, 그 역이 언제나 참인 것은 아니다. 예를 들어 한 변수에서 c(x)=−x2≥0c(x)=-x^2\geq0c(x)=−x2≥0이면 허용점은 0 하나뿐이다. 그런데 c′(0)=0c'(0)=0c′(0)=0이므로 선형화된 부등식은 모든 방향을 허용한다. 일차 근사가 실제 기하를 전혀 구분하지 못하는 경우다.

제약 자격은 이런 불일치를 통제하는 정칙성 가정이다. LICQ는 등식과 활성 부등식의 기울기들이 선형독립이라는 조건이다. 국소 최소점에서 LICQ가 성립하면 KKT 승수의 존재를 얻고 승수도 유일하다. 제약의 개수가 많다는 사실만으로 성립 여부를 결정할 수는 없고 활성 기울기들의 관계를 조사해야 한다.

MFCQ는 등식 기울기의 독립성과 함께, 등식의 접방향이면서 모든 활성 부등식을 엄격히 안쪽으로 늘리는 방향이 존재한다는 조건이다. LICQ보다 약한 조건이므로 어떤 종속 활성 기울기들을 허용한다. 볼록 문제에서 자주 쓰는 Slater 조건은 또 다른 관점으로, 적절한 볼록 구조와 엄격한 실행 가능점을 사용한다. 이 조건들을 이름만 바꾼 같은 가정으로 취급하지 않는다.

KKT 네 조건을 분리해서 검사한다

매끄러운 문제의 국소 최소점에서 적절한 제약 자격이 성립하면 다음 조건을 만족하는 승수가 존재한다.

∇xL(x,λ)=0,ci(x)=0 (i∈E),ci(x)≥0 (i∈I),\nabla_xL(x,\lambda)=0,\qquad c_i(x)=0\ (i\in\mathcal E),\qquad c_i(x)\geq0\ (i\in\mathcal I),∇x​L(x,λ)=0,ci​(x)=0 (i∈E),ci​(x)≥0 (i∈I),
λi≥0 (i∈I),λici(x)=0 (i∈I).\lambda_i\geq0\ (i\in\mathcal I),\qquad \lambda_i c_i(x)=0\ (i\in\mathcal I).λi​≥0 (i∈I),λi​ci​(x)=0 (i∈I).

정상성은 목적함수 기울기가 제약의 법선 방향들로 균형을 이룬다는 뜻이다. 상보성은 여유가 있는 부등식에는 0의 승수가 대응함을 뜻한다. 활성 제약의 승수가 반드시 양수인 것은 아니다. 활성인데 승수가 0인 경우도 있고, 모든 활성 부등식 승수가 양수인 상황은 엄격 상보성이라는 별도 조건이다.

필요조건의 논리는 가능한 방향으로 비용이 일차 감소할 수 없다는 데서 출발한다. 제약 자격으로 실제 가능한 방향과 선형화 기하를 연결하면, 분리 논리로 기울기들의 균형과 승수 부호를 얻을 수 있다. 앞의 c=−x2≥0c=-x^2\geq0c=−x2≥0에서 f(x)=xf(x)=xf(x)=x를 최소화하면 0은 유일한 허용점이라 최소점이지만, 1−λc′(0)=11-\lambda c'(0)=11−λc′(0)=1이어서 KKT 정상성을 만족하는 승수는 없다. 최소점이 틀린 것이 아니라 정칙성 가정이 실패한 것이다.

일반 비볼록 문제에서 KKT는 후보를 거르는 조건이며 충분조건이 아니다. 반면 fff가 볼록이고, 부등식 cic_ici​가 오목하며, 등식이 아핀인 경우에는 KKT를 만족하는 실행 가능점의 전역 최적성을 라그랑지안 하한으로 확인할 수 있다. 어떤 제약 자격이 승수의 존재에 쓰이는지와, 이미 주어진 KKT 점의 충분성을 증명하는 데 무엇이 필요한지를 구분한다.

이차 조건은 모든 방향을 검사하지 않는다

제약 아래에서는 이동할 수 없거나 일차 비용이 이미 증가하는 방향의 곡률까지 모두 양수일 필요가 없다. 핵심은 선형화 제약을 만족하고 목적함수가 일차로 변하지 않는 임계방향이다. KKT 점에서 양의 승수를 가진 활성 제약은 이런 방향에 대해 등식처럼 작동하고, 승수 0인 활성 제약은 한쪽 부등식 방향을 남길 수 있다.

두 번 연속 미분 가능하고 LICQ가 성립하는 국소 최소점에서 이차 필요조건은 임계방향 ddd에서 dT∇xx2L d≥0d^T\nabla^2_{xx}L\,d\geq0dT∇xx2​Ld≥0를 요구한다. 모든 0 아닌 임계방향에서 엄격히 양수인 조건은 표준적인 이차 충분조건의 핵심이다. 여기의 헤시안은 목적함수만의 헤시안이 아니라 라그랑지안의 헤시안이라는 점이 중요하다. 제약 자체의 곡률도 들어간다.

예를 들어 f(x)=3x12−2x22f(x)=3x_1^2-2x_2^2f(x)=3x12​−2x22​를 등식 x2=x1x_2=x_1x2​=x1​ 위에서 최소화하면 허용 집합에서는 f=x12f=x_1^2f=x12​다. 전체 헤시안에는 음의 고유값이 있지만 접방향 d=(t,t)d=(t,t)d=(t,t)에서는 dT∇2f d=2t2>0d^T\nabla^2f\,d=2t^2>0dT∇2fd=2t2>0이다. 따라서 원점은 제약 아래 엄격 최소다. 전체 공간에서의 안장점이라는 분류를 제약 문제에 그대로 가져오면 잘못 판단한다.

승수의 민감도와 쌍대성

승수는 제약의 작은 변화가 최적값에 미치는 영향을 나타낼 수 있다. 그러나 부호는 파라미터가 제약에 어떻게 들어갔는지에 달려 있다. c(x,b)=b−aTx≥0c(x,b)=b-a^Tx\geq0c(x,b)=b−aTx≥0처럼 상한 bbb를 늘리면 허용 집합이 넓어진다. 해와 승수가 충분히 매끄럽게 변하는 조건에서 최적값 v(b)v(b)v(b)의 도함수는 −λ-\lambda−λ다.

쌍대 함수는 q(λ)=inf⁡xL(x,λ)q(\lambda)=\inf_x L(x,\lambda)q(λ)=infx​L(x,λ)다. 부등식 승수가 음이 아니면 실행 가능 xxx에서 L(x,λ)≤f(x)L(x,\lambda)\leq f(x)L(x,λ)≤f(x)이므로 q(λ)q(\lambda)q(λ)는 원시 최적값의 하한이다. 이것이 약한 쌍대성이다. 하한이 실제 최적값과 같아지는 강한 쌍대성은 별도 조건을 요구한다. 볼록성과 적절한 Slater 조건은 대표적인 충분한 틀이고, 일반 비볼록 문제에는 간극이 남을 수 있다.

승수는 제약식의 스케일에도 의존한다. 동일한 부등식을 양의 상수로 곱하면 허용 집합은 같지만 그 승수는 반대로 스케일된다. 따라서 승수 숫자를 단위나 정규화 없이 서로 비교해서 “더 중요한 제약”이라고 판단하지 않는다. 활성 집합이 바뀌는 지점에서는 최적값의 미분 가능성도 다시 확인해야 한다.

import argparse
import json
import os

os.environ.setdefault('MPLCONFIGDIR',tempfile.mkdtemp(prefix='opt-mpl-'))

import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from matplotlib import font_manager

def main():
    p=argparse.ArgumentParser(description=__doc__);p.add_argument('--output-dir',type=Path,default=Path('output'));args=p.parse_args();args.output_dir.mkdir(parents=True,exist_ok=True)
    a=np.array([2.,1.5]);normal=np.array([1.,2.]);b=3.
    def project(bound):
        lam=max(0.,float((normal@a-bound)/(normal@normal)));x=a-lam*normal
        return x,lam,float(.5*(x-a)@(x-a))
    x,lam,value=project(b);slack=float(b-normal@x);stationarity=float(np.linalg.norm(x-a+lam*normal));dual=float(lam*(normal@a-b)-.5*lam**2*(normal@normal));h=1e-5;derivative=(project(b+h)[2]-project(b-h)[2])/(2*h)
    assert np.allclose(x,[1.6,.7]) and abs(lam-.4)<1e-14
    assert stationarity<1e-14 and slack>=-1e-14 and abs(lam*slack)<1e-14
    assert abs(value-dual)<1e-14 and abs(derivative+lam)<1e-9
    results={'solution':x.tolist(),'multiplier':lam,'objective':value,'constraint_slack':slack,'stationarity_norm':stationarity,'complementarity_absolute':abs(lam*slack),'dual_value':dual,'duality_gap':abs(value-dual),'value_derivative_finite_difference':derivative,'sensitivity_error':abs(derivative+lam)}
    font=Path('/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc')
    if font.exists():font_manager.fontManager.addfont(str(font));plt.rcParams['font.family']=font_manager.FontProperties(fname=str(font)).get_name()
    plt.rcParams.update({'axes.unicode_minus':False,'font.size':10,'axes.spines.top':False,'axes.spines.right':False})
    fig,axs=plt.subplots(1,2,figsize=(11,5.2),layout='constrained');xx,yy=np.meshgrid(np.linspace(-.2,3,240),np.linspace(-.2,2.5,240));cost=.5*((xx-a[0])**2+(yy-a[1])**2)
    axs[0].contourf(xx,yy,(xx+2*yy<=b).astype(float),levels=[.5,1.5],colors=['#e5f2eb']);axs[0].contour(xx,yy,cost,levels=[.1,.4,.8,1.5,2.5],colors='#aebac7');line=np.linspace(-.2,3,100);axs[0].plot(line,(b-line)/2,color='#2d8b76',lw=2,label='활성 경계');axs[0].plot([a[0],x[0]],[a[1],x[1]],'--',color='#d67931');axs[0].scatter(*a,s=55,color='#d67931',label='무제약 최소점');axs[0].scatter(*x,s=100,marker='*',color='#3b6fb6',label='제약 최소점');axs[0].set(xlim=(-.2,3),ylim=(-.2,2.5),xlabel=r'$x_1$',ylabel=r'$x_2$',title='녹색 영역 안에서 가장 가까운 점');axs[0].legend(fontsize=8,loc='upper left')
    bs=np.linspace(.5,6,180);vals=np.array([project(bb)[2] for bb in bs]);axs[1].plot(bs,vals,color='#3b6fb6',lw=2,label='최적값 v(b)');near=np.linspace(2.2,3.8,50);axs[1].plot(near,value-lam*(near-b),'--',color='#d67931',label='b=3에서의 접선');axs[1].scatter(b,value,color='#d67931');axs[1].axvline(5,color='#aebac7',ls=':');axs[1].set(xlabel='허용 상한 b',ylabel='최적 목적함수값',title='상한을 풀어주면 비용이 감소한다');axs[1].legend(fontsize=9);axs[1].grid(alpha=.2)
