최적화 알고리즘은 미분값이 정확하다는 전제 위에서 설계되는 경우가 많다. 그러나 실제 프로그램에서는 함수가 다른 프로그램을 호출하고, 변수의 단위가 다르고, 작은 차이가 부동소수점 오차에 묻힌다. 이 장의 핵심은 미분 공식을 아는 것에서 한 걸음 더 나아가, 미분을 계산하는 경로와 그 결과를 검사하는 경로를 분리하는 것이다.

학습 목표

  • 유한차분의 절단오차와 반올림오차가 경쟁하는 이유를 설명한다
  • 전체 야코비안, 방향미분, 헤시안 벡터 곱 가운데 필요한 대상을 고른다
  • 자동미분의 전진 모드와 역방향 모드를 입력·출력 차원으로 비교한다
  • 구현 오류, 비매끄러움, 평가 노이즈를 구별하는 미분 검사법을 설계한다

미분이 무엇을 뜻하는지 먼저 정한다

스칼라 함수 f:Rn→Rf:\mathbb R^n\to\mathbb Rf:Rn→R의 기울기 ggg는 모든 편미분을 모은 벡터다. 방향 vvv에 대한 변화율은 gTvg^TvgTv다. 벡터 함수 F:Rn→RmF:\mathbb R^n\to\mathbb R^mF:Rn→Rm의 야코비안 JJJ는 m×nm\times nm×n 행렬이며, JvJvJv는 입력을 vvv 방향으로 움직였을 때 모든 출력의 일차 변화를 나타낸다. JTwJ^TwJTw는 출력에 가중치 www를 준 스칼라 조합의 입력 민감도다.

알고리즘이 HvHvHv만 요구하는데 n2n^2n2개의 헤시안 성분을 전부 만드는 것은 불필요할 수 있다. 반대로 전체 야코비안이 필요한 선형계 풀이에서 방향미분 하나를 계산하고 미분 준비가 끝났다고 생각해도 안 된다. 미분 대상, 모양, 변수 순서, 단위를 함수의 입출력 계약처럼 명확히 적는 것이 첫 단계다.

유한차분에서 간격이 너무 작으면 생기는 일

한 변수의 전진차분과 중앙차분은 각각 다음과 같다.

Dh+f(x)=f(x+h)−f(x)h,Dh0f(x)=f(x+h)−f(x−h)2h.D_h^+f(x)=\frac{f(x+h)-f(x)}h,\qquad D_h^0f(x)=\frac{f(x+h)-f(x-h)}{2h}.Dh+​f(x)=hf(x+h)−f(x)​,Dh0​f(x)=2hf(x+h)−f(x−h)​.

충분히 매끄럽고 도함수들이 근방에서 제어되면 전진차분의 절단오차는 O(h)O(h)O(h), 중앙차분은 O(h2)O(h^2)O(h2)다. 이것은 정확한 실수 연산에서 테일러 전개로 얻는 결론이다. 컴퓨터에서는 비슷한 두 함수값을 빼면서 유효 자릿수를 잃고, 그 차이를 작은 hhh로 나누면서 평가 오차를 키울 수 있다.

함수 규모를 포함한 상수들을 생략하면 총 오차를 대략 다음처럼 생각할 수 있다.

Eforward(h)≈C1h+C2uh,Ecentral(h)≈C3h2+C4uh.E_{\rm forward}(h)\approx C_1h+C_2\frac{u}{h},\qquad E_{\rm central}(h)\approx C_3h^2+C_4\frac{u}{h}.Eforward​(h)≈C1​h+C2​hu​,Ecentral​(h)≈C3​h2+C4​hu​.

uuu는 기계 정밀도의 규모다. 두 항의 균형으로부터 전진차분에는 h∼uh\sim\sqrt uh∼u​, 중앙차분에는 h∼u1/3h\sim u^{1/3}h∼u1/3이라는 출발점이 나온다. 이는 차원이 없는 스케일링된 변수와 적당한 상수에서의 안내선이다. 함수가 매우 크거나 거의 평평하거나 내부 솔버 오차가 크면 최적 간격은 달라진다.

다변수에서 모든 좌표에 같은 절대 간격을 적용하면 단위 차이를 무시하게 된다. 길이와 온도처럼 크기가 다른 변수는 먼저 무차원화하거나 각 변수의 대표 크기에 맞춰 간격을 고른다. 경계 근처에서는 중앙차분이 허용 영역 밖을 평가할 수 있다. 이때는 한쪽 차분, 변수 변환, 또는 정의역을 고려한 별도 계산이 필요하다.

희소 구조를 아는 것은 평가 횟수를 줄인다

좌표별 전진차분으로 조밀한 야코비안을 만들면 기준 평가 외에 대략 nnn회의 벡터 함수 평가가 필요하다. 어떤 출력이 어떤 입력에 의존하는지 알면 함께 교란해도 효과가 겹치지 않는 열들을 묶을 수 있다. 열 교차 그래프를 색칠하는 방식이 이런 압축 평가를 구성하는 한 방법이다.

같은 그룹에 들어간 두 열이 어떤 행에서 동시에 0이 아니면, 하나의 차분 출력만으로 각 열의 기여를 분리할 수 없다. 따라서 희소 패턴을 추측해서 잘못 묶는 것은 단순히 덜 정확한 근사가 아니라 잘못된 미분 행렬을 만들 수 있다. 안전하게 알려진 구조를 사용하고, 작은 문제에서 조밀 계산과 대조한 뒤 큰 문제로 옮기는 것이 좋다.

방향미분 검사도 유용하다. 무작위 단위벡터 vvv를 고정하고 g(x)Tvg(x)^Tvg(x)Tv를 중앙차분 (f(x+hv)−f(x−hv))/(2h)(f(x+hv)-f(x-hv))/(2h)(f(x+hv)−f(x−hv))/(2h)와 비교하면 기울기 전체를 여러 번 재계산하지 않고 많은 성분 오류를 포착할 수 있다. 한 방향을 통과했다고 모든 성분이 맞는 것은 아니므로 여러 방향, 여러 점, 여러 간격을 검사한다.

자동미분은 프로그램의 연쇄법칙이다

자동미분은 유한차분으로 함수값을 빼는 방법도, 수식을 대수적으로 단순화하는 기호미분도 아니다. 실행되는 기본 연산들의 도함수를 연쇄법칙으로 연결한다. 예를 들어 z1=xyz_1=xyz1​=xy, z2=exp⁡(z1)z_2=\exp(z_1)z2​=exp(z1​), f=z2+x2f=z_2+x^2f=z2​+x2로 계산하면 각 연산을 따라 입력의 작은 변화 또는 출력의 민감도를 전달할 수 있다.

전진 모드는 입력 방향 vvv를 주고 각 중간 변수의 방향미분을 함께 계산해 JvJvJv를 얻는다. 입력 차원이 작거나 몇 개 방향만 필요할 때 자연스럽다. 역방향 모드는 출력 가중치에서 시작해 민감도를 거꾸로 전달하여 JTwJ^TwJTw를 얻는다. 출력이 하나인 큰 최적화 문제에서는 한 역방향 계산으로 전체 기울기를 얻을 수 있어 유리하다.

하지만 역방향 계산에는 중간 값의 저장 또는 재계산이 필요하다. 메모리가 부족하면 체크포인팅으로 일부 중간값을 다시 계산하는 선택을 할 수 있다. 헤시안 벡터 곱은 미분을 적절히 중첩해 구할 수 있으며, 어떤 모드를 조합할지는 함수 구조와 메모리 제약에 달려 있다. 여기의 독립 실습은 자동미분 라이브러리를 사용하지 않으므로 자동미분 성능을 측정한 결과로 해석하면 안 된다.

자동미분이 반환한 숫자라고 항상 의도한 수학 문제의 미분인 것은 아니다. 정수 변환, 클리핑, 분기, 반복 종료 조건, 비미분 가능한 연산이 의미를 바꿀 수 있다. 특히 ∣x∣|x|∣x∣의 0점처럼 수학적으로 미분이 존재하지 않는 곳에서는 어떤 구현 규칙이 선택되었는지 확인해야 한다. 수치 검사는 자동미분을 쓸 때도 가치가 있다.

"""Independent derivative error experiment. Run: python chapter08.py --output-dir out"""
import argparse
import json
import os
import tempfile
from pathlib import Path
os.environ.setdefault('MPLCONFIGDIR', tempfile.mkdtemp(prefix='opt-mpl-'))
os.environ.setdefault('XDG_CACHE_HOME', tempfile.mkdtemp(prefix='opt-cache-'))
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from matplotlib import font_manager

def main():
    parser=argparse.ArgumentParser(description=__doc__);parser.add_argument('--output-dir',type=Path,default=Path('output'))
    args=parser.parse_args();args.output_dir.mkdir(parents=True,exist_ok=True)
    def f(x): return np.exp(x)+np.sin(3*x)
    x=.37; exact=np.exp(x)+3*np.cos(3*x);h=np.logspace(-16,-1,151)
    forward=np.abs((f(x+h)-f(x))/h-exact)
    central=np.abs((f(x+h)-f(x-h))/(2*h)-exact)
    complex_step=np.abs(np.imag(f(x+1j*h))/h-exact)
    assert central.min() < 1e-8
    assert abs(np.imag(f(x+1e-20j))/1e-20-exact) < 1e-12
    assert forward[0] > forward.min()*1e4
    results={'point':x,'exact_derivative':float(exact),'best_forward_error':float(forward.min()),'best_forward_h':float(h[forward.argmin()]),'best_central_error':float(central.min()),'best_central_h':float(h[central.argmin()]),'complex_step_error_h1e20':float(abs(np.imag(f(x+1e-20j))/1e-20-exact))}
    font=Path('/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc')
    if font.exists():
        font_manager.fontManager.addfont(str(font));plt.rcParams['font.family']=font_manager.FontProperties(fname=str(font)).get_name()
    plt.rcParams.update({'axes.unicode_minus':False,'font.size':11,'axes.spines.top':False,'axes.spines.right':False})
    fig,ax=plt.subplots(figsize=(9.6,5.5),layout='constrained')
    floor=1e-16
    for error,label,color in [(forward,'전진차분','#3b6fb6'),(central,'중앙차분','#d67931'),(complex_step,'복소 스텝','#2d8b76')]:
        ax.loglog(h,np.maximum(error,floor),label=label,color=color,lw=2)
    ax.set(xlabel='스텝 크기 h',ylabel='미분값의 절대오차 · 표시 하한 1e−16',title='8장  차분 간격을 계속 줄이면 정확해질까')
    ax.grid(alpha=.22,which='both');ax.legend()
    # English fallback when the optional local Korean font is absent.
    translations = {'전진차분': 'Forward difference', '중앙차분': 'Central difference', '복소 스텝': 'Complex step', '스텝 크기 h': 'Step size h', '미분값의 절대오차 · 표시 하한 1e−16': 'Absolute derivative error · display floor 1e-16', '8장  차분 간격을 계속 줄이면 정확해질까': 'Chapter 8 · Does a smaller difference step improve accuracy?'}
    if not Path('/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc').exists():
        for artist in fig.findobj(matplotlib.text.Text):
            artist.set_text(translations.get(artist.get_text(), artist.get_text()))
    fig.savefig(args.output_dir/'chapter08.png',dpi=160);plt.close(fig)
    (args.output_dir/'chapter08.json').write_text(json.dumps(results,ensure_ascii=False,indent=2)+'\n');print(json.dumps(results,ensure_ascii=False))
if __name__=='__main__':main()
