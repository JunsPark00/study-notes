선형계획법은 직선으로 만든 문제이지만, 계산은 단순한 연립방정식 풀이보다 풍부하다. 제약이 만드는 다면체에서 어떤 면을 따라 움직이고, 어떤 변수를 0에 고정하며, 언제 더 좋아질 가능성이 사라졌다고 증명할지를 함께 결정해야 한다. 이 장은 작은 생산 계획을 직접 풀면서 기저, 감소 비용, 쌍대 인증의 연결을 설명한다.

학습 목표

  • 기본 실행 가능 해와 꼭짓점의 관계를 설명한다
  • 감소 비용과 비율 검사가 각각 무엇을 보장하는지 구분한다
  • 원시·쌍대 실행 가능성과 목적값 차이로 최적성을 확인한다
  • 실제 솔버에 필요한 초기화, 퇴화 대책, 전처리의 역할을 이해한다

13.1 최적성은 쌍대 인증으로 확인한다

표준형을 min⁡cTx\min c^TxmincTx, Ax=bAx=bAx=b, x≥0x\ge0x≥0로 쓰자. 이 장에서는 A∈Rm×nA\in\mathbb R^{m\times n}A∈Rm×n가 행 독립이며 m≤nm\le nm≤n이라고 가정한다. 등식 승수를 yyy로 두고 라그랑지안을 L=cTx−yT(Ax−b)−sTxL=c^Tx-y^T(Ax-b)-s^TxL=cTx−yT(Ax−b)−sTx로 정한다. 따라서 쌍대 문제는 max⁡bTy\max b^TymaxbTy, ATy+s=cA^Ty+s=cATy+s=c, s≥0s\ge0s≥0다. yyy는 부호 제한이 없지만 비음수 변수의 승수 sss는 비음수여야 한다.

마지막 등식은 원시와 쌍대가 모두 실행 가능할 때의 관계다. 둘 다 실행 가능하고 xTs=0x^Ts=0xTs=0이면 더 좋은 원시 해가 존재할 수 없다. 이 때문에 목적값 하나만 보고 종료하기보다 Ax−bAx-bAx−b, ATy+s−cA^Ty+s-cATy+s−c, 음수 성분, 상보성을 각각 확인한다. 수치 잔차가 있으면 계산한 목적값 차이와 xTsx^TsxTs가 정확히 같지는 않다. 큰 계수의 문제에는 절대 잔차뿐 아니라 데이터 크기로 나눈 잔차도 필요하다.

13.2 기저가 꼭짓점을 표현하는 방식

AAA의 독립인 열 mmm개를 골라 BBB라 하고 나머지 열을 NNN이라 하자. 비기저 변수 xN=0x_N=0xN​=0을 대입하면 BxB=bBx_B=bBxB​=b가 된다. 이 해가 xB≥0x_B\ge0xB​≥0이면 기본 실행 가능 해다. 표준형의 이러한 해는 다면체의 꼭짓점을 표현한다. 다만 하나의 꼭짓점이 여러 기저로 표현될 수 있고, 기저 변수 가운데 0이 있으면 퇴화가 나타난다.

기저는 단순한 정수 인덱스 묶음이 아니다. 현재 자유롭게 움직일 수 있는 좌표계와 선형계를 함께 정한다. B−1B^{-1}B−1를 수식에 쓰더라도 프로그램에서 역행렬을 직접 저장할 필요는 없다. Bv=wBv=wBv=w와 BTy=cBB^Ty=c_BBTy=cB​를 선형계로 풀면 된다. 큰 문제에서는 희소 분해를 유지하며 기저 열이 바뀔 때 갱신하는 기술이 성능의 중심이다.

직접 계산 · 두 제품의 생산 계획

제품 생산량을 x,yx,yx,y라 하고 판매 가치를 각각 4, 3으로 잡는다. 첫 공정은 제품별로 2, 1의 자원을, 두 번째 공정은 1, 2의 자원을 소비한다. 각 공정 용량은 8이고 첫 제품에는 추가 상한 3이 있다. 이 수치는 설명을 위해 새로 만든 모델이다.

min⁡−4x−3ys.t.2x+y≤8,x+2y≤8,x≤3,x,y≥0.\min -4x-3y\quad\text{s.t.}\quad 2x+y\le8,\quad x+2y\le8,\quad x\le3,\quad x,y\ge0.min−4x−3ys.t.2x+y≤8,x+2y≤8,x≤3,x,y≥0.

각 상한에 여유 변수를 추가하면 3개 등식과 5개 비음수 변수를 얻는다. 여유 변수만 기저로 선택하면 시작점은 (0,0)(0,0)(0,0)이다. 첨부 코드는 음수 감소 비용 중 가장 작은 변수 번호를 진입 변수로 고른다. 이 규칙에서는 (0,0)→(3,0)→(3,2)→(8/3,8/3)(0,0)\to(3,0)\to(3,2)\to(8/3,8/3)(0,0)→(3,0)→(3,2)→(8/3,8/3)으로 세 번 피벗한다. 첫 두 제약의 교점을 대입하면 최적 비용은 −56/3-56/3−56/3이다.

최종 표준형 쌍대 승수는 y=(−5/3,−2/3,0)y=(-5/3,-2/3,0)y=(−5/3,−2/3,0)이다. 원래의 상한 제약을 8−2x−y≥08-2x-y\ge08−2x−y≥0처럼 적을 때의 비음수 승수는 (5/3,2/3,0)(5/3,2/3,0)(5/3,2/3,0)이므로 부호가 반대다. 이는 오류가 아니라 등식 여유 변수와 부등식 표현의 차이다. 첫 두 공정의 한 단위 용량 증가가 최소 비용을 각각 약 5/35/35/3, 2/32/32/3 낮춘다는 국소 민감도 해석도 얻는다. 이 해석은 같은 기저가 유효한 작은 변화에 한정된다.

그림 확대

그림은 새 모델에서 계산한 꼭짓점 경로와 목적값이다. 독립 실행에서 해의 최대 성분 오차는 4.44×10−164.44\times10^{-16}4.44×10−16, 원시 잔차와 계산된 쌍대 간극은 표시 정밀도에서 0이었다. 모든 가능한 작은 기저를 열거한 결과 및 HiGHS 쌍대 심플렉스의 목적값과도 대조했다. 이 결과는 이 예제의 검사이며 일반적인 구현 정확성 증명은 아니다.

13.4 선형대수와 13.5 초기화·퇴화

작은 예제는 매번 조밀한 선형계를 다시 풀어도 부담이 작다. 그러나 실제 revised simplex는 전체 표를 반복해서 만들기보다 필요한 기저 해와 감소 비용을 계산한다. 분해 갱신이 누적되면 오차가 커질 수 있어 주기적인 재분해, 잔차 보정, 스케일 조정이 중요하다. 거의 종속인 열을 기저로 고르면 비율이나 감소 비용의 부호도 불안정해진다.

처음부터 실행 가능한 기저를 아는 것은 특별한 상황이다. 일반 문제에는 인공 변수를 사용하는 Phase I 등 초기화 절차가 필요하다. Phase I의 최적 목적값이 충분히 양수라면 원문제 실행 불가능성을 의심한다. 이를 원문제의 비유계와 혼동하면 안 된다. 퇴화에서는 θ=0\theta=0θ=0이 되어 기저는 바뀌지만 점과 비용은 그대로일 수 있다. 잘못된 피벗 선택은 순환을 일으킬 수 있으며, 정확 연산에서 Bland 규칙은 순환 방지 수단 중 하나다. 유한 정밀도에서는 허용 오차와 안정적인 피벗 선택까지 함께 고려한다.

13.6 쌍대 심플렉스, 13.7 전처리, 13.8 방법 선택

원시 심플렉스가 실행 가능성을 유지하며 쌍대 조건을 맞추는 방향이라면, 쌍대 심플렉스는 쌍대 실행 가능성을 유지하며 원시 위반을 고친다. 최적 기저를 알고 있는 상태에서 우변이나 일부 제약이 바뀌는 재최적화에 유용할 수 있다. “쌍대”라는 이름이 원래와 무관한 다른 문제를 푼다는 뜻은 아니다. 서로 다른 인증 조건을 출발점으로 같은 최적 조건을 향한다.

전처리는 고정 변수 제거, 명백한 모순 검출, 상·하한 강화, 중복 행 처리로 실제 계산 규모를 줄인다. 제거한 변수를 원래 좌표로 복원하고 원래 제약에서 잔차를 검사하는 후처리도 같은 만큼 중요하다. 전처리 후 목적값만 맞는다는 이유로 원래 모델 검증을 생략해서는 안 된다.

심플렉스와 내부점 가운데 어느 하나가 모든 문제에서 빠르지는 않다. 희소 구조, 반복해서 푸는 유사 문제, 원하는 기저 출력, 퇴화 정도가 선택에 영향을 준다. 다음 장은 같은 생산 모델에 내부점 경로를 적용하므로 이동 방식의 차이를 직접 비교할 수 있다. 단, 두 교육용 코드의 실행 시간으로 산업용 알고리즘의 우열을 판정하지는 않는다.

자주 생기는 오해

  • 기저 변수라고 모두 양수인 것은 아니다. 퇴화 해에서는 0도 가능하다
  • 정수 생산량이 필요하다면 이 LP 해를 반올림하는 것만으로 정수 최적화가 끝나지 않는다
  • 쌍대 간극이 작아도 원시·쌍대 실행 가능성이 나쁘면 최적성 인증이 아니다
  • 기저 전수 열거는 독립 검증용이다. 후보 수가 조합적으로 늘어 대규모 해법이 되지 않는다

연습 문제와 힌트

"""Original, self-contained numerical experiment. No network or external data.
Run: python chapter13.py --output-dir ./results
Requires NumPy, SciPy and Matplotlib. An installed Korean font is optional.
If unavailable, all plot labels fall back to English; --english forces this mode.
"""
import argparse
import json
import platform
from pathlib import Path
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser()
parser.add_argument("--output-dir", type=Path, default=Path("."))
parser.add_argument("--english", action="store_true", help="Use English plot labels")
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc")]
font_paths += [Path(f.fname) for f in font_manager.fontManager.ttflist
               if any(s in f.name for s in ("Noto Sans CJK", "Nanum", "Malgun", "AppleGothic"))]
font_path = next((p for p in font_paths if p.exists()), None)
if args.english:
    font_path = None
if font_path is not None:
    font_manager.fontManager.addfont(str(font_path))
font_family = font_manager.FontProperties(fname=str(font_path)).get_name() if font_path else "DejaVu Sans"
plt.rcParams.update({"font.family": font_family,
                     "axes.unicode_minus": False, "font.size": 11,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f7f9fc", "axes.facecolor": "#f7f9fc",
                     "axes.prop_cycle": matplotlib.cycler(color=["#156f87", "#e07945", "#7661a9", "#278169"])})

ENGLISH_LABELS = {'실행 가능 영역': 'Feasible region', '직접 구현한 피벗': 'Implemented pivots', '최적점': 'Optimum', '생산량 x': 'Production x', '생산량 y': 'Production y', '기저를 바꾸며 경계를 이동': 'Moving between bases', '독립 계산한 최적 비용': 'Independent optimum', '피벗 단계': 'Pivot step', '최소화 목적값': 'Objective value', '감소 비용이 이동을 결정': 'Reduced costs guide the move'}
def tr(label):
    return label if font_path else ENGLISH_LABELS[label]

def finish(chapter, fig, metrics):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160)
    plt.close(fig)
    report = {"chapter": chapter, "plot_language": "ko" if font_path else "en",
              "versions": {"python": platform.python_version(), "numpy": np.__version__,
                           "scipy": scipy.__version__, "matplotlib": matplotlib.__version__},
              "metrics": metrics}
    serialized = json.dumps(report, ensure_ascii=False, allow_nan=False, indent=2)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(serialized + "\n", encoding="utf-8")
    print(json.dumps(report, ensure_ascii=False, allow_nan=False))

from itertools import combinations
from scipy.optimize import linprog

# Standard form: min c.T x, A x = b, x >= 0.
A = np.array([[2.,1.,1.,0.,0.], [1.,2.,0.,1.,0.], [1.,0.,0.,0.,1.]])
b = np.array([8.,8.,3.])
c = np.array([-4.,-3.,0.,0.,0.])
basis = [2,3,4]
path = []
for iteration in range(20):
    B = A[:, basis]
    xb = np.linalg.solve(B, b)
    y = np.linalg.solve(B.T, c[basis])
    reduced = c - A.T @ y
    x = np.zeros(5); x[basis] = xb
    path.append(x.copy())
    candidates = [j for j in range(5) if j not in basis and reduced[j] < -1e-10]
    if not candidates:
        break
    entering = min(candidates)  # Bland entering rule.
    direction = np.linalg.solve(B, A[:, entering])
    eligible = np.where(direction > 1e-12)[0]
    if eligible.size == 0:
        raise RuntimeError("Unbounded along the selected edge")
    ratios = xb[eligible] / direction[eligible]
    theta = ratios.min()
    tied = eligible[np.abs(ratios-theta) < 1e-10]
    leaving = min(tied, key=lambda i: basis[i])
    basis[leaving] = entering
else:
    raise RuntimeError("Iteration limit")

# Independent small-problem certificate by enumerating every nonsingular basis.
vertices = []
for inds in combinations(range(5),3):
    if abs(np.linalg.det(A[:,inds])) < 1e-10:
        continue
    v = np.zeros(5); v[list(inds)] = np.linalg.solve(A[:,inds], b)
    if np.min(v) >= -1e-10:
        vertices.append(v)
reference = linprog(c, A_eq=A, b_eq=b, method="highs-ds")
assert reference.success
expected = np.array([8/3,8/3,0,0,1/3])
metrics = {"objective": float(c@x), "solution_error": float(np.linalg.norm(x-expected,np.inf)),
           "primal_residual": float(np.linalg.norm(A@x-b,np.inf)),
           "dual_violation": float(max(0.,-reduced.min())),
           "duality_gap": float(abs(c@x-b@y)), "pivots": len(path)-1,
           "basis_enumeration_gap": float(abs(c@x-min(c@v for v in vertices))),
           "highs_objective_gap": float(abs(reference.fun-c@x))}
assert metrics["solution_error"] < 1e-9
assert max(metrics[k] for k in ("primal_residual","dual_violation","duality_gap","basis_enumeration_gap","highs_objective_gap")) < 1e-9
fig, ax = plt.subplots(1,2, figsize=(10,4.6), layout="constrained")
poly = np.array([[0,0],[3,0],[3,2],[8/3,8/3],[0,4],[0,0]])
ax[0].fill(poly[:,0],poly[:,1],color="#dceef0",label=tr("실행 가능 영역"))
q=np.array(path)
ax[0].plot(q[:,0],q[:,1],"o-",lw=2,label=tr("직접 구현한 피벗"))
for k,pt in enumerate(q): ax[0].annotate(str(k),(pt[0]+.05,pt[1]+.08))
ax[0].scatter([8/3],[8/3],marker="*",s=150,color="#e07945",label=tr("최적점"))
ax[0].set(xlabel=tr("생산량 x"),ylabel=tr("생산량 y"),title=tr("기저를 바꾸며 경계를 이동"),xlim=(-.15,3.7),ylim=(-.2,4.6))
ax[0].legend(fontsize=9,loc="upper right")
ax[1].plot(np.arange(len(path)),q@c,"o-",lw=2)
ax[1].axhline(-56/3,color="#e07945",ls="--",label=tr("독립 계산한 최적 비용"))
ax[1].set(xlabel=tr("피벗 단계"),ylabel=tr("최소화 목적값"),title=tr("감소 비용이 이동을 결정"))
ax[1].set_xticks(np.arange(len(path))); ax[1].legend(fontsize=9)
finish(13,fig,metrics)
