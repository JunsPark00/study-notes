심플렉스는 꼭짓점의 표현을 바꾸며 이동했다. 내부점 방법은 양수인 변수와 승수를 함께 유지하면서 최적성 방정식의 잔차를 줄인다. “안쪽으로 이동한다”는 그림만으로는 핵심이 드러나지 않는다. 중심 경로, 뉴턴 방정식, 양수성, 원시·쌍대 잔차가 어떻게 연결되는지를 이해해야 한다.

학습 목표

  • LP의 KKT 조건에서 완화된 상보성 방정식을 만든다
  • 원시·쌍대 뉴턴 방향과 경계까지의 단계 길이를 계산한다
  • 불능 시작과 실행 가능 시작의 차이를 설명한다
  • 단순 중심화와 예측·보정 알고리즘을 구분하고 종료 잔차를 읽는다

14.1 중심 경로는 상보성을 잠시 완화한다

XXX는 xxx를 대각에 놓은 행렬이며 eee는 모든 성분이 1인 벡터다. 이 방정식을 만족하는 점들을 장벽 계수에 따라 이은 것이 중심 경로다. 중심 경로의 통상적인 존재·유일성 논의에는 행 독립성과 적절한 엄격 실행 가능성 등 가정이 필요하다. 모든 LP가 이 조건을 원래 형태 그대로 만족하는 것은 아니다.

원시와 쌍대가 실행 가능하면 목적값 차이는 xTs=nμx^Ts=n\muxTs=nμ다. 따라서 μ\muμ를 줄인다는 것은 계산을 최적성에 가까이 가져가는 명확한 척도다. 다만 불능 시작 반복에서는 μ=xTs/n\mu=x^Ts/nμ=xTs/n가 작다는 사실만으로 원문제의 목적값 차이가 작다고 단정할 수 없다. 등식 잔차가 여전히 클 수 있기 때문이다.

X,SX,SX,S가 양의 대각행렬이면 변수를 소거하여 더 작은 시스템을 만들 수 있다. 예를 들어 정상방정식에는 AXS−1ATAXS^{-1}A^TAXS−1AT 형태가 나타난다. 행 독립인 AAA에 대해 양의 정부호이지만, 경계 근처에서 xi/six_i/s_ixi​/si​가 극단적인 값을 가지면 조건수가 나빠질 수 있다. 시스템 크기만 보고 정상방정식이 항상 더 낫다고 판단해서는 안 된다. 증강 시스템과 희소 분해의 안정성까지 고려한다.

14.2 양수성을 지키는 단계 길이

뉴턴 방향을 얻어도 한 번에 모두 이동할 수 있는 것은 아니다. Δxi<0\Delta x_i<0Δxi​<0인 성분은 경계까지의 거리를 제한한다. 안전 비율 τ∈(0,1)\tau\in(0,1)τ∈(0,1)를 두면 다음과 같이 원시 단계 길이를 정할 수 있다.

αp=min⁡(1,τmin⁡Δxi<0−xiΔxi).\alpha_p=\min\left(1,\tau\min_{\Delta x_i<0}\frac{-x_i}{\Delta x_i}\right).αp​=min(1,τΔxi​<0min​Δxi​−xi​​).

음수 방향 성분이 없으면 해당 최솟값 제한을 생략한다. 쌍대 여유 sss에도 같은 규칙으로 αd\alpha_dαd​를 계산한다. 등식 승수 yyy에는 양수성 제한이 없지만, 쌍대 방정식의 구조를 유지하기 위해 보통 sss와 같은 단계 길이로 갱신한다. 이 예제는 τ=0.995\tau=0.995τ=0.995를 사용한다. 수치적으로 경계에 정확히 도달하지 않게 하려는 선택이지 보편적인 최적 상수는 아니다.

실용적인 예측·보정 방법은 먼저 중심화 없는 방향으로 개선 가능성을 예상하고, 예상 상보성에 맞추어 중심화와 곱의 이차항을 보정한다. 하나의 분해를 여러 우변에 재사용할 수 있다는 장점도 있다. 아래 교육용 코드는 이 전체 전략을 구현하지 않는다. 고정 σ=0.15\sigma=0.15σ=0.15로 잔차를 줄이는 불능 시작 원시·쌍대 뉴턴 반복이며, 예측·보정과 비교하는 출발점으로 삼는다.

직접 계산 · 꼭짓점 대신 양수 경로로

13장의 새 생산 모델을 그대로 사용한다. 최소화 비용은 −4x−3y-4x-3y−4x−3y이고 제약은 2x+y≤82x+y\le82x+y≤8, x+2y≤8x+2y\le8x+2y≤8, x≤3x\le3x≤3, x,y≥0x,y\ge0x,y≥0이다. 3개 여유 변수를 넣은 5차원 표준형에서 모든 xi=si=1x_i=s_i=1xi​=si​=1, y=0y=0y=0으로 시작한다. 양수성은 만족하지만 Ax=bAx=bAx=b와 ATy+s=cA^Ty+s=cATy+s=c는 만족하지 않는다.

따라서 그림의 초반 점은 모든 원래 제약을 만족하는 궤적으로 해석하면 안 된다. 특히 등식에 연결된 slack 값과 실제 여유가 처음에는 다를 수 있다. “내부점”이 항상 모든 원래 제약의 내부에서만 움직인다는 뜻은 아니다. 이 구현에서 항상 양수로 유지하는 대상은 표준형의 원시 변수와 쌍대 여유다.

최적 생산량은 x=y=8/3x=y=8/3x=y=8/3, 최소 비용은 −56/3-56/3−56/3이다. 첨부 코드의 독립 실행에서는 13번 갱신 후 원시 잔차가 표시 정밀도에서 0, 쌍대 잔차는 8.88×10−168.88\times10^{-16}8.88×10−16, 평균 상보성은 9.56×10−119.56\times10^{-11}9.56×10−11이었다. 목적값의 원시·쌍대 차이는 약 4.78×10−104.78\times10^{-10}4.78×10−10으로 평균 상보성의 5배와 일치한다. 이는 이 시점의 실행 가능성 잔차도 충분히 작기 때문이다.

그림 확대

왼쪽은 5차원 변수 가운데 생산량 두 성분만 보여 준다. 오른쪽은 원시 잔차, 쌍대 잔차, 평균 상보성을 별도로 그렸다. 0에 가까운 잔차를 로그 축에 표시하기 위해 그림에서만 작은 양수로 바닥을 두었으며, 실제 검증에는 원래 수치를 사용한다. SciPy의 HiGHS 내부점 결과와 비용을 비교한 차이는 약 1.91×10−101.91\times10^{-10}1.91×10−10이었다.

14.3 시작점, 확장, 종료 판정

불능 시작은 양수인 x,sx,sx,s만 준비한 뒤 원시·쌍대 방정식을 점차 맞추는 접근이다. 임의의 문제에서 성공을 무조건 보장하는 장치가 아니며, 실행 불가능 또는 비유계 상태를 구분할 별도 절차가 필요하다. 실용 솔버는 전처리, 초기점 보정, 정칙화, 상태 인증 등을 포함한다. 균질 자기쌍대 임베딩은 최적해와 불능 인증을 통합적으로 다루는 한 방향이지만 여기서는 구현하지 않는다.

변수에 상한이 있거나 자유 변수가 존재하면 표준형으로 바꾸거나 그 구조를 직접 다루는 방정식을 사용한다. 자유 변수를 두 비음수 변수의 차로 바꿀 수 있지만 변수가 늘고 수치 구조가 달라진다. 원래 모델을 무조건 표준형으로 팽창시키는 것보다 솔버가 지원하는 범위를 이용하는 것이 유리할 때도 많다.

종료는 한 수치로 결정하지 않는다. 원시 위반, 쌍대 위반, 상보성을 모두 데이터 크기에 맞는 기준과 비교한다. 목적 계수를 크게 배율 조정하면 같은 절대 정상성 잔차의 의미도 달라진다. 문제가 실패했을 때 단순히 반복 횟수를 늘리기보다 스케일, 행의 종속성, 상태 메시지를 먼저 조사한다. 작은 목적 변화나 작은 단계는 정체를 나타낼 수도 있다.

14.4 실용 솔버를 읽는 관점

내부점 해는 최적 면 가까이에 있지만 명시적인 최적 기저를 주지 않을 수 있다. 실제 LP 솔버는 crossover 과정으로 기저 해를 얻기도 한다. 그래서 사용자에게 보이는 최종 해가 꼭짓점이라고 해서 내부점 알고리즘이 사용되지 않았다고 단정할 수 없다. 반대로 내부점 반복 수와 crossover 횟수를 하나의 동일한 반복 수로 비교해서도 안 된다.

이번 작은 조밀 선형계는 개념을 보기 위한 선택이다. 대규모 LP에서는 희소성, fill-in, 수치 정칙화, 병렬 선형대수의 영향이 크다. 심플렉스와의 비교도 같은 모델, 같은 허용 오차, 같은 전처리 조건에서 해야 한다. 이 장의 그림은 알고리즘의 이동과 인증 차이를 보여 주며 속도 순위를 제시하지 않는다.

주의할 점과 연습

  • x,s>0x,s>0x,s>0만으로 원시·쌍대 실행 가능성이 보장되지는 않는다
  • 중심화 계수를 너무 작게 두면 경계 근처의 불균형이 심해질 수 있다
  • 표시된 로그 그래프의 바닥과 실제 0 잔차를 구분한다
  1. 위 문제에서 최종 xTsx^TsxTs가 평균 상보성의 몇 배인지 설명하라. 힌트: 상보성 쌍은 생산 변수와 여유 변수를 합쳐 5개다
  2. x=(2,1)x=(2,1)x=(2,1), Δx=(−4,1)\Delta x=(-4,1)Δx=(−4,1)일 때 τ=0.9\tau=0.9τ=0.9의 단계 길이를 구하라. 힌트: 첫 성분이 경계를 제한하며 결과는 0.45다
  3. σ\sigmaσ를 0.05와 0.5로 바꾸어 잔차 곡선을 비교하라. 힌트: 반복 수뿐 아니라 가장 작은 양수 성분과 최종 인증 잔차도 기록한다
  4. 비용을 1000배로 바꾸고 절대 종료 기준의 한계를 관찰하라. 힌트: 해의 위치는 같아도 승수와 쌍대 잔차의 자연스러운 크기는 달라진다

"""Original, self-contained numerical experiment. No network or external data.
Run: python chapter14.py --output-dir ./results
Requires NumPy, SciPy and Matplotlib. An installed Korean font is optional.
If unavailable, all plot labels fall back to English; --english forces this mode.
"""
import argparse
import json
import platform
from pathlib import Path
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser()
parser.add_argument("--output-dir", type=Path, default=Path("."))
parser.add_argument("--english", action="store_true", help="Use English plot labels")
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc")]
font_paths += [Path(f.fname) for f in font_manager.fontManager.ttflist
               if any(s in f.name for s in ("Noto Sans CJK", "Nanum", "Malgun", "AppleGothic"))]
font_path = next((p for p in font_paths if p.exists()), None)
if args.english:
    font_path = None
if font_path is not None:
    font_manager.fontManager.addfont(str(font_path))
font_family = font_manager.FontProperties(fname=str(font_path)).get_name() if font_path else "DejaVu Sans"
plt.rcParams.update({"font.family": font_family,
                     "axes.unicode_minus": False, "font.size": 11,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f7f9fc", "axes.facecolor": "#f7f9fc",
                     "axes.prop_cycle": matplotlib.cycler(color=["#156f87", "#e07945", "#7661a9", "#278169"])})

ENGLISH_LABELS = {'원시 변수의 첫 두 성분': 'First two primal variables', 'LP 최적점': 'LP optimum', '불능 시작 원시·쌍대 경로': 'Infeasible-start primal-dual path', '원시 잔차': 'Primal residual', '쌍대 잔차': 'Dual residual', '평균 상보성': 'Mean complementarity', '반복': 'Iteration', '잔차 / 평균 상보성': 'Residual / mean complementarity', '양수성과 방정식 잔차를 함께 관리': 'Residuals and complementarity'}
def tr(label):
    return label if font_path else ENGLISH_LABELS[label]

def finish(chapter, fig, metrics):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160)
    plt.close(fig)
    report = {"chapter": chapter, "plot_language": "ko" if font_path else "en",
              "versions": {"python": platform.python_version(), "numpy": np.__version__,
                           "scipy": scipy.__version__, "matplotlib": matplotlib.__version__},
              "metrics": metrics}
    serialized = json.dumps(report, ensure_ascii=False, allow_nan=False, indent=2)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(serialized + "\n", encoding="utf-8")
    print(json.dumps(report, ensure_ascii=False, allow_nan=False))

from scipy.optimize import linprog

A=np.array([[2.,1.,1.,0.,0.],[1.,2.,0.,1.,0.],[1.,0.,0.,0.,1.]])
b=np.array([8.,8.,3.]); c=np.array([-4.,-3.,0.,0.,0.])
m,n=A.shape
x=np.ones(n); s=np.ones(n); y=np.zeros(m)
history=[]; path=[]
def boundary(v,d):
    neg=d<0
    return min(1., .995*np.min(-v[neg]/d[neg])) if np.any(neg) else 1.
for k in range(80):
    rp=A@x-b; rd=A.T@y+s-c; mu=x@s/n
    history.append([np.linalg.norm(rp,np.inf),np.linalg.norm(rd,np.inf),mu])
    path.append(x.copy())
    if max(history[-1]) < 1e-10:
        break
    K=np.block([[np.zeros((n,n)),A.T,np.eye(n)],
                [A,np.zeros((m,m)),np.zeros((m,n))],
                [np.diag(s),np.zeros((n,m)),np.diag(x)]])
    rhs=np.r_[-rd,-rp,.15*mu*np.ones(n)-x*s]
    step=np.linalg.solve(K,rhs)
    dx,dy,ds=step[:n],step[n:n+m],step[n+m:]
    ap=boundary(x,dx); ad=boundary(s,ds)
    x+=ap*dx; y+=ad*dy; s+=ad*ds
    assert min(x.min(),s.min()) > 0
else: raise RuntimeError("No convergence")
reference=linprog(c,A_eq=A,b_eq=b,method="highs-ipm")
assert reference.success
metrics={"objective":float(c@x),"primal_residual":float(np.linalg.norm(A@x-b,np.inf)),
         "dual_residual":float(np.linalg.norm(A.T@y+s-c,np.inf)),
         "mean_complementarity":float(x@s/n),"duality_gap":float(abs(c@x-b@y)),
         "solution_error":float(np.linalg.norm(x[:2]-8/3,np.inf)),
         "highs_objective_gap":float(abs(c@x-reference.fun)),"iterations":k}
assert metrics["solution_error"] < 1e-7
assert max(metrics[t] for t in ("primal_residual","dual_residual","duality_gap","highs_objective_gap")) < 1e-7
fig,ax=plt.subplots(1,2,figsize=(10,4.6),layout="constrained")
poly=np.array([[0,0],[3,0],[3,2],[8/3,8/3],[0,4],[0,0]])
ax[0].fill(poly[:,0],poly[:,1],color="#dceef0")
p=np.array(path); ax[0].plot(p[:,0],p[:,1],"o-",ms=4,label=tr("원시 변수의 첫 두 성분"))
ax[0].scatter([8/3],[8/3],s=130,marker="*",color="#e07945",label=tr("LP 최적점"))
ax[0].set(xlabel="x",ylabel="y",title=tr("불능 시작 원시·쌍대 경로"),xlim=(-.15,3.7),ylim=(-.15,4.5))
ax[0].legend(fontsize=9)
h=np.maximum(np.array(history),1e-16)
for j,label in enumerate([tr("원시 잔차"),tr("쌍대 잔차"),tr("평균 상보성")]): ax[1].semilogy(h[:,j],"o-",ms=3,label=label)
ax[1].set(xlabel=tr("반복"),ylabel=tr("잔차 / 평균 상보성"),title=tr("양수성과 방정식 잔차를 함께 관리"))
ax[1].legend(fontsize=9)
finish(14,fig,metrics)
