학습 목표

  • 뉴턴 방정식의 내부 잔차와 원래 최적화 문제의 기울기를 구분한다

  • 반복 횟수와 실행 시간을 혼동하지 않고 실험 결과를 해석한다

큰 문제에서 무엇이 비싸지는가

내부 선형계를 얼마나 정확히 풀 것인가

부정확 뉴턴 방법은 방향이 다음 조건을 만족하면 내부 계산을 멈출 수 있다.

∥Hkpk+gk∥≤ηk∥gk∥,0≤ηk<1.\|H_kp_k+g_k\|\leq\eta_k\|g_k\|,\qquad 0\leq\eta_k<1.∥Hk​pk​+gk​∥≤ηk​∥gk​∥,0≤ηk​<1.

왼쪽은 뉴턴 선형계의 잔차다. 원래 문제의 최적성 잔차 ∥gk∥\|g_k\|∥gk​∥와는 다르다. 아직 해에서 멀리 떨어져 있는데 내부 선형계를 매우 정밀하게 풀면, 곧 버릴 국소 모델에 계산을 과하게 쓰게 된다. 반대로 해 근방에서도 ηk\eta_kηk​를 크게 유지하면 뉴턴 방법의 빠른 국소 수렴을 충분히 활용하지 못한다.

적절한 매끄러움, 해에서의 비특이성, 충분히 가까운 시작점이 있을 때, forcing term ηk\eta_kηk​를 0으로 보내는 선택은 초선형 국소 수렴과 연결된다. ηk\eta_kηk​를 기울기 크기에 비례해 더 빠르게 줄이는 선택은 추가 조건 아래 이차 수렴을 얻는 데 쓰인다. 이 문장들은 모든 초기점에서의 보장이 아니다. 멀리서 안정적으로 접근하려면 선 탐색이나 신뢰영역 같은 전역화 장치가 별도로 필요하다.

양의 정부호 헤시안에는 CG를 내부 솔버로 쓸 수 있다. 비볼록 문제에서 dTHkd≤0d^TH_kd\leq0dTHk​d≤0인 방향이 발견되면 평범한 SPD 선형계처럼 계속 진행해서는 안 된다. 절단 뉴턴이나 신뢰영역 방법은 이 음의 곡률 정보를 받아서 안전한 방향 또는 경계 스텝을 정한다. 헤시안이 비특이하다는 조건만으로 뉴턴 방향이 하강 방향이 되는 것도 아니다.

사전조건화는 좌표의 균형을 바꾼다

SPD 행렬 MMM을 선택하고 M−1rM^{-1}rM−1r를 싸게 구할 수 있다고 하자. 사전조건화 CG는 개념적으로 M−1/2HM−1/2M^{-1/2}HM^{-1/2}M−1/2HM−1/2의 스펙트럼을 다룬다. 좋은 MMM은 문제의 주요 스케일 차이를 흡수하지만, 구성과 적용 비용이 너무 크면 이득이 사라진다. 대각 사전조건화는 저렴한 출발점일 뿐, 모든 강한 결합이나 나쁜 조건수를 해결하는 만능 장치는 아니다.

조건수가 작아지면 최악의 경우 오차 상계가 개선될 수 있다. 실제 수렴은 고유값의 군집, 초기 잔차의 방향, 유한정밀도 효과에도 영향을 받는다. 따라서 조건수 하나만 보고 정확한 반복 횟수를 예언하지 않는다. 비교할 때는 같은 잔차 정의와 종료 허용오차를 사용하고, 사전조건화 준비 시간도 비용에 포함한다.

L-BFGS와 구조를 이용하는 방법

L-BFGS는 최근 mmm개의 이동 si=xi+1−xis_i=x_{i+1}-x_isi​=xi+1​−xi​와 기울기 차이 yi=gi+1−giy_i=g_{i+1}-g_iyi​=gi+1​−gi​만 저장한다. 조밀한 역헤시안 근사 Bk−1B_k^{-1}Bk−1​를 명시적으로 만들지 않고 두 번의 재귀 순회로 그 근사와 벡터의 곱을 계산한다. 주요 저장량과 곱셈 비용은 O(mn)O(mn)O(mn)이다. m=7m=7m=7, n=100,000n=100{,}000n=100,000이면 쌍 자체의 저장량은 약 11.2MB지만, 작업 벡터와 프로그램 전체 메모리는 이보다 크다.

곡률 조건 siTyi>0s_i^Ty_i>0siT​yi​>0은 양의 정부호 근사를 유지하는 데 중요하다. 매끄러운 문제에서 적절한 Wolfe 선 탐색은 이 조건을 확보하는 데 도움을 준다. 노이즈가 크거나 곡률이 아주 작으면 업데이트를 건너뛰거나 감쇠하는 처리가 필요할 수 있다. 기억 길이를 늘리는 것은 더 많은 정보를 보존하지만 과거 곡률이 현재 지역에도 적합하다는 보장은 없다.

희소 헤시안과 제한 메모리는 다른 개념이다. 전자는 함수의 의존 관계에서 0 성분이 생기는 구조이고, 후자는 정보를 얼마나 오래 기억할지에 관한 알고리즘 선택이다. 일반적인 조밀 BFGS 업데이트 뒤에 작은 성분을 임의로 0으로 만들면 secant 관계나 양의 정부호성이 깨질 수 있다. 희소 준뉴턴은 원하는 구조와 업데이트 조건을 함께 고려해야 한다.

부분 분리 함수는 작은 변수 집합에만 의존하는 항들의 합으로 쓸 수 있다.

f(x)=∑e=1Nefe(Uex),∇2f(x)v=∑eUeT∇2fe(Uex)Uev.f(x)=\sum_{e=1}^{N_e}f_e(U_ex),\qquad \nabla^2 f(x)v=\sum_eU_e^T\nabla^2 f_e(U_ex)U_ev.f(x)=e=1∑Ne​​fe​(Ue​x),∇2f(x)v=e∑​UeT​∇2fe​(Ue​x)Ue​v.

UeU_eUe​는 관련 성분을 고르는 행렬이다. 이 표현은 국소 미분 계산, 희소 조립, 병렬 계산을 설계하는 단서가 된다. 다만 여러 항이 같은 변수를 공유하면 완전히 독립적인 최적화 문제로 나눌 수는 없다. 공유 변수에 대한 기울기와 곡률을 합쳐야 한다.

그림 확대

그래프의 세로축은 로그 척도다. 잔차는 매 반복에서 단조 감소할 필요가 없다. 이 실험은 특정 행렬의 내부 선형계 비용을 보여주며, 대규모 비선형 문제 전체의 실행 시간이나 L-BFGS와의 우열을 입증하지 않는다. 기준 해를 만들고 오차를 검사하는 작업 비용도 실제 최적화 반복 비용과 분리해 읽어야 한다.

흔한 실수와 연습

작은 내부 잔차를 곧바로 작은 최적화 오차로 해석하지 않는다. HkH_kHk​가 나쁘게 조건화되어 있으면 선형계 잔차와 방향 오차의 비율이 클 수 있다. 또한 내부 반복 수가 적은 방법이 반드시 총 시간도 짧은 것은 아니다. 전처리, 함수 평가, 통신, 메모리 이동까지 보고해야 한다.

  1. 5DTD5D^TD5DTD의 계수를 0으로 바꾸면 대각 PCG는 몇 번에 끝날까? 힌트: 이때 M=QM=QM=Q이므로 변환된 행렬은 항등행렬이다.
  2. 모든 did_idi​를 1로 바꾸면 사전조건화의 이득은 어떻게 달라질까? 힌트: 스케일 불균형과 이웃 결합의 영향을 따로 생각한다.
  3. L-BFGS의 쌍 저장량이 조밀한 행렬 하나와 같아지는 mmm은 얼마인가? 힌트: 2mn=n22mn=n^22mn=n2를 풀되, 이것은 저장량 비교이지 같은 알고리즘이라는 뜻은 아니다.
  4. 종료 기준을 10−510^{-5}10−5로 완화하고 두 방법의 실제 잔차와 해 오차를 비교하라. 힌트: 기준을 바꿨을 때의 결과를 기존 실행 수치와 섞지 않는다.

def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--output-dir', type=Path, default=Path('output'))
    args = parser.parse_args(); args.output_dir.mkdir(parents=True, exist_ok=True)
    n = 180; diagonal = np.geomspace(1.0, 1000.0, n)
    def matvec(v):
        out = diagonal * v
        diff = np.diff(v)
        out[:-1] -= 5 * diff; out[1:] += 5 * diff
        return out
    truth = np.sin(np.linspace(0, 2*np.pi, n))
    b = matvec(truth); jacobi = diagonal + 10; jacobi[[0,-1]] -= 5
    def cg(precondition):
        x = np.zeros(n); r = b.copy(); z = precondition(r); p = z.copy(); rz = r @ z
        hist = [float(np.linalg.norm(r)/np.linalg.norm(b))]
        for _ in range(1500):
            qp = matvec(p); curvature = p @ qp
            assert curvature > 0
            alpha = rz / curvature; x += alpha*p; r -= alpha*qp
            hist.append(float(np.linalg.norm(r)/np.linalg.norm(b)))
            if hist[-1] < 1e-11: break
            z = precondition(r); next_rz = r @ z; p = z+(next_rz/rz)*p; rz = next_rz
        actual = float(np.linalg.norm(matvec(x)-b)/np.linalg.norm(b))
        assert actual < 2e-11
        assert np.linalg.norm(x-truth)/np.linalg.norm(truth) < 1e-8
        return x, hist, actual
    x, h1, r1 = cg(lambda r:r)
    xp, h2, r2 = cg(lambda r:r/jacobi)
    results = {'n':n,'cg_iterations':len(h1)-1,'pcg_iterations':len(h2)-1,'cg_true_relative_residual':r1,'pcg_true_relative_residual':r2,'pcg_relative_solution_error':float(np.linalg.norm(xp-truth)/np.linalg.norm(truth)),'dense_hessian_bytes_n100000':8*100000**2,'lbfgs_pair_bytes_n100000_m7':8*2*100000*7}
    assert results['pcg_iterations'] < results['cg_iterations']
    style(); fig, ax = plt.subplots(figsize=(9.6,5.5),layout='constrained')
    ax.semilogy(h1,label='CG · 사전조건화 없음',color='#3b6fb6',lw=2)
    ax.semilogy(h2,label='PCG · 대각 사전조건화',color='#d67931',lw=2)
    ax.axhline(1e-11,color='#7d8791',ls=':',label='종료 기준')
    ax.set(xlabel='행렬 벡터 곱을 수행한 반복 수',ylabel='상대 선형계 잔차',title='7장  같은 이차문제, 서로 다른 내부 반복 비용')
    ax.grid(alpha=.22);ax.legend(loc='upper right')
    # English fallback when the optional local Korean font is absent.
    translations = {'CG · 사전조건화 없음': 'CG · no preconditioner', 'PCG · 대각 사전조건화': 'PCG · diagonal preconditioner', '종료 기준': 'Stopping tolerance', '행렬 벡터 곱을 수행한 반복 수': 'Iterations / matrix-vector products', '상대 선형계 잔차': 'Relative linear-system residual', '7장  같은 이차문제, 서로 다른 내부 반복 비용': 'Chapter 7 · One quadratic, different inner iteration costs'}
    if not Path('/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc').exists():

            artist.set_text(translations.get(artist.get_text(), artist.get_text()))
