최급강하가 매번 가장 가파른 방향을 새로 고른다면, 켤레기울기 방법은 앞서 해결한 방향의 성과를 덜 방해하도록 다음 방향을 만든다. 대칭 양의 정부호 선형계에서 시작한 아이디어가 비선형 최적화로 확장되지만, 두 경우의 보장을 같은 것으로 읽어서는 안 된다.

학습 목표와 준비

  • 선형계 풀이와 볼록 이차함수 최소화의 동등성을 이해한다
  • 잔차, 보통 직교, 행렬에 대한 켤레성, Krylov 공간을 구분한다
  • 전처리가 바꾸는 기하와 원래 선형계의 검증 기준을 설명한다
  • 비선형 CG의 계수, 선 탐색, 재시작에 필요한 주의를 정리한다

선수 지식은 내적, 대칭 양의 정부호 행렬, 정확 선 탐색이다. 이 장의 코드에서는 잔차를 r=b−Axr=b-Axr=b−Ax로 정의한다. Ax−bAx-bAx−b를 잔차로 정의한 다른 문헌과 비교할 때는 방향의 부호까지 함께 확인한다.

5.1 선형계를 최소화 문제로 본다

A=AT≻0A=A^T\succ0A=AT≻0이면 다음 이차함수는 유일한 최소점을 갖는다.

q(x)=12xTAx−bTx,∇q(x)=Ax−b.q(x)=\tfrac12x^TAx-b^Tx, \qquad\nabla q(x)=Ax-b.q(x)=21​xTAx−bTx,∇q(x)=Ax−b.

기울기 0은 곧 Ax=bAx=bAx=b다. 역행렬을 직접 만들 필요 없이 행렬·벡터 곱을 이용해 이 해에 접근할 수 있다. 큰 희소 문제에서는 AAA를 밀집 행렬로 저장하지 않고 v↦Avv\mapsto Avv↦Av 연산만 제공하는 방식이 특히 유용하다.

서로 다른 방향 pi,pjp_i,p_jpi​,pj​가 piTApj=0p_i^TAp_j=0piT​Apj​=0을 만족하면 AAA에 대해 켤레라고 한다. 일반적인 직교인 piTpj=0p_i^Tp_j=0piT​pj​=0과 다르다. 양의 정부호 행렬의 제곱근으로 변환한 벡터 A1/2piA^{1/2}p_iA1/2pi​들이 보통 직교한다고 생각하면, 켤레성이 문제의 곡률을 반영한 직교라는 뜻이 된다.

이 방향들 위에서 순서대로 정확 선 탐색을 하면, 뒤의 이동이 앞 방향에서 이미 만족시킨 최적성 조건을 다시 망가뜨리지 않는다. CG는 모든 방향을 미리 저장하고 직교화하는 대신 짧은 점화식으로 필요한 구조를 만든다.

αk=rkTrkpkTApk,xk+1=xk+αkpk,rk+1=rk−αkApk,βk=rk+1Trk+1rkTrk,pk+1=rk+1+βkpk.\begin{aligned} \alpha_k&=\frac{r_k^Tr_k}{p_k^TAp_k},\\ x_{k+1}&=x_k+\alpha_kp_k,\\ r_{k+1}&=r_k-\alpha_kAp_k,\\ \beta_k&=\frac{r_{k+1}^Tr_{k+1}}{r_k^Tr_k},\\ p_{k+1}&=r_{k+1}+\beta_kp_k. \end{aligned}αk​xk+1​rk+1​βk​pk+1​​=pkT​Apk​rkT​rk​​,=xk​+αk​pk​,=rk​−αk​Apk​,=rkT​rk​rk+1T​rk+1​​,=rk+1​+βk​pk​.​

정확 산술에서는 잔차들이 서로 직교하고 탐색 방향들이 서로 켤레가 된다. 반복점은 다음 Krylov 공간에 초기점을 더한 집합에서 에너지 오차를 최소화한다.

5.4 조건수뿐 아니라 고유값 분포도 본다

CG의 대표적인 에너지 오차 경계는 다음과 같다.

∥xk−x∗∥A∥x0−x∗∥A≤2(κ−1κ+1)k,κ=λmax⁡(A)λmin⁡(A).\frac{\|x_k-x^*\|_A}{\|x_0-x^*\|_A} \leq2\left(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\right)^k, \qquad\kappa=\frac{\lambda_{\max}(A)}{\lambda_{\min}(A)}.∥x0​−x∗∥A​∥xk​−x∗∥A​​≤2(κ​+1κ​−1​)k,κ=λmin​(A)λmax​(A)​.

조건수가 크면 이 경계는 느린 감소를 예측한다. 그러나 CG는 고유값에 작용하는 다항식을 만들며 오차를 줄이므로, 고유값이 몇 군데로 모여 있으면 같은 조건수라도 더 빠르게 수렴할 수 있다. 극단값 두 개만 보고 모든 반복 수를 예언할 수 없는 이유다.

또한 에너지 오차와 유클리드 잔차 노름은 같은 양이 아니다. 이차 목적값이나 에너지 오차가 감소하는 동안 잔차 노름이 일시적으로 증가할 수 있다. 그림의 잔차 곡선에 봉우리가 있다고 즉시 구현 오류라고 판단하지 않는다. 어떤 노름에 대한 정리를 보고 있는지부터 확인한다.

5.5 전처리는 쉬운 보조계를 사용하는 일이다

전처리 행렬 M≻0M\succ0M≻0는 AAA의 중요한 구조를 근사하면서 Mz=rMz=rMz=r을 저렴하게 풀 수 있어야 한다. 전처리 CG에서는 zk=M−1rkz_k=M^{-1}r_kzk​=M−1rk​를 사용하고 계수를 다음처럼 바꾼다.

αk=rkTzkpkTApk,βk=rk+1Tzk+1rkTzk,pk+1=zk+1+βkpk.\alpha_k=\frac{r_k^Tz_k}{p_k^TAp_k},\qquad \beta_k=\frac{r_{k+1}^Tz_{k+1}}{r_k^Tz_k},\qquad p_{k+1}=z_{k+1}+\beta_kp_k.αk​=pkT​Apk​rkT​zk​​,βk​=rkT​zk​rk+1T​zk+1​​,pk+1​=zk+1​+βk​pk​.

이론적으로는 M−1/2AM−1/2M^{-1/2}AM^{-1/2}M−1/2AM−1/2라는 대칭 양의 정부호 행렬의 고유값을 보는 것이 자연스럽다. M−1AM^{-1}AM−1A는 일반적으로 유클리드 내적에서 대칭이 아니므로 기본 CG 코드를 그 행렬에 무심코 적용하는 방식과 구분해야 한다.

Jacobi 전처리는 MMM을 AAA의 대각으로 둔다. 변수별 크기 차이는 줄여도 비대각 결합까지 없애지는 않는다. 불완전 Cholesky나 문제 구조를 이용한 전처리는 더 좋은 근사를 줄 수 있지만 구성·적용 비용과 메모리가 든다. 반복 수만 줄었다고 전체 실행 시간이 반드시 좋아지는 것은 아니다.

5.6 비선형 CG에서는 무엇이 달라질까

일반 매끄러운 함수에서는 새 기울기 gk+1g_{k+1}gk+1​를 사용해 다음 방향을 만든다.

pk+1=−gk+1+βkpk.p_{k+1}=-g_{k+1}+\beta_kp_k.pk+1​=−gk+1​+βk​pk​.

Fletcher–Reeves와 Polak–Ribière의 대표적인 계수는 다음과 같다.

βkFR=∥gk+1∥2∥gk∥2,βkPR=gk+1T(gk+1−gk)∥gk∥2.\beta_k^{FR}=\frac{\|g_{k+1}\|^2}{\|g_k\|^2},\qquad \beta_k^{PR}=\frac{g_{k+1}^T(g_{k+1}-g_k)}{\|g_k\|^2}.βkFR​=∥gk​∥2∥gk+1​∥2​,βkPR​=∥gk​∥2gk+1T​(gk+1​−gk​)​.

PR+는 max⁡(0,βkPR)\max(0,\beta_k^{PR})max(0,βkPR​)를 사용하여 음의 값에서는 최급강하로 되돌아간다. 그러나 이것만으로 모든 단계가 하강 방향이 된다고 보장할 수는 없다. 현재 기울기와 새 방향의 내적을 검사하고 필요하면 이전 방향을 버리는 재시작이 중요하다.

선 탐색도 방향식과 함께 설계해야 한다. 예를 들어 FR의 하강성과 수렴을 논의할 때에는 강한 Wolfe 곡률 상수를 더 제한하는 등의 조건을 사용한다. 선형 CG에서 얻은 직교성, 켤레성, 유한 종료를 비선형 함수에 그대로 옮기지 않는다. 반복 횟수 외에 기울기·함수 평가 횟수, 재시작 횟수, 최종 잔차를 함께 기록하는 것이 좋다.

독립 실험과 읽는 법

독립 실행 예제 내려받기는 위 2차원 손계산을 검증하고, 별도의 60차원 비대각 SPD 계에서 기본 CG와 Jacobi 전처리 CG를 비교한다. 행렬은 대각 3, 이웃 성분 −0.6-0.6−0.6인 삼대각 행렬에 좌표별 크기 1부터 30까지의 변환을 적용해 만든다. 우변 난수의 시드는 20261001로 고정했다.

그림 확대

새 실행에서 기본 CG는 129회, Jacobi 전처리 CG는 16회에 상대 참 잔차 10−1010^{-10}10−10 미만을 달성했다. 마지막 잔차는 각각 약 3.14×10−113.14\times10^{-11}3.14×10−11, 3.06×10−113.06\times10^{-11}3.06×10−11이었다. 대칭 전처리 행렬의 조건수는 약 2.33이고 원래 행렬은 약 1379.25다. 60차원인데 129회가 걸린 사실은 유한 정밀도에서 차원 수만으로 반복을 제한하면 안 된다는 예이기도 하다.

이 코드는 원리를 드러내려고 작은 밀집 행렬을 사용한다. 대규모 희소 저장, 정교한 잔차 보정, 비선형 CG의 전체 선 탐색 구현까지 제공하는 생산용 솔버는 아니다. 마지막 해는 직접 선형계 풀이와 비교하고, 상대 참 잔차와 켤레성 검사에 단언문을 둔다.

자주 하는 실수와 연습

  • 잔차의 부호를 바꾸고 방향의 부호는 유지하지 않는다
  • 전처리 잔차가 작다는 이유만으로 원래 계의 오차를 생략하지 않는다
  • CG의 모든 잔차 노름이 단조 감소한다고 가정하지 않는다
  1. 손계산 예의 두 방향을 보통 내적으로 곱하면 0인가? 힌트: 값은 5/95/95/9이다. 켤레성과 보통 직교가 다름을 확인하라.
  2. Jacobi 전처리가 정확한 역연산이 되는 행렬은? 힌트: 양의 대각행렬에서는 M=AM=AM=A이다. 비대각 결합이 있는 이번 실험과 구분한다.
  3. 비선형 새 방향에서 gk+1Tpk+1>0g_{k+1}^Tp_{k+1}>0gk+1T​pk+1​>0이면 어떻게 할까? 힌트: pk+1=−gk+1p_{k+1}=-g_{k+1}pk+1​=−gk+1​로 재시작하면 기울기가 0이 아닌 한 하강성이 회복된다. 이것만으로 전체 수렴 정리가 완성되는 것은 아니다.

#!/usr/bin/env python3
"""Original, self-contained teaching experiment. Not a production optimizer.
Run: python chapter05.py --output-dir ./output
Only NumPy, SciPy and Matplotlib are required. No network or private data.
"""
from pathlib import Path
import argparse, json, os, platform, tempfile
os.environ.setdefault("MPLCONFIGDIR", str(Path(tempfile.gettempdir()) / "optimization-learning-mpl"))
os.environ.setdefault("XDG_CACHE_HOME", str(Path(tempfile.gettempdir()) / "optimization-learning-cache"))
Path(os.environ["XDG_CACHE_HOME"]).mkdir(parents=True, exist_ok=True)
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser(description=__doc__)
parser.add_argument("--output-dir", type=Path, default=Path("."))
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"),
              Path("/usr/share/fonts/truetype/nanum/NanumGothic.ttf")]
korean = False
for font_path in font_paths:
    if font_path.exists():
        font_manager.fontManager.addfont(str(font_path))
        plt.rcParams["font.family"] = font_manager.FontProperties(fname=str(font_path)).get_name()
        korean = True
        break
plt.rcParams.update({"axes.unicode_minus": False, "font.size": 10,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f8fafc", "axes.facecolor": "#f8fafc"})
def label(ko, en):
    return ko if korean else en

def finish(chapter, fig, results):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160, bbox_inches=None)
    plt.close(fig)
    results.update({"chapter": chapter, "seed": 20261001,
                    "python": platform.python_version(), "numpy": np.__version__,
                    "scipy": scipy.__version__, "matplotlib": matplotlib.__version__,
                    "korean_labels": korean, "checks_passed": True})
    output = json.dumps(results, ensure_ascii=False, indent=2, allow_nan=False)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(output + "\n", encoding="utf-8")
    print(output)

def cg(A,b,precondition=False,tolerance=1e-10,maxiter=1000):
    x=np.zeros_like(b); r=b-A@x
    diagonal=np.diag(A) if precondition else np.ones_like(b)
    z=r/diagonal; p=z.copy(); rz=float(r@z)
    history=[float(np.linalg.norm(r)/np.linalg.norm(b))]; directions=[]
    for _ in range(maxiter):
        ap=A@p; denom=float(p@ap)
        if denom<=0: raise ValueError("CG needs SPD curvature")
        directions.append(p.copy())
        alpha=rz/denom; x=x+alpha*p; r=r-alpha*ap
        true=float(np.linalg.norm(b-A@x)/np.linalg.norm(b))
        history.append(true)
        if true<tolerance: break
        z=r/diagonal; next_rz=float(r@z)
        p=z+(next_rz/rz)*p; rz=next_rz
    else: raise RuntimeError("CG exhausted iterations")
    return x,np.array(history),np.array(directions)
small=np.array([[3.,1.],[1.,2.]]); rhs=np.array([1.,2.])
xs,hs,ps=cg(small,rhs,tolerance=1e-13)
assert len(hs)-1==2 and np.linalg.norm(xs-[0.,1.])<1e-12
normalized_conjugacy=abs(float(ps[0]@small@ps[1]))/np.sqrt(float(ps[0]@small@ps[0])*float(ps[1]@small@ps[1]))
assert normalized_conjugacy<1e-12
n=60; scale=np.geomspace(1.,30.,n)
T=np.diag(np.full(n,3.))+np.diag(np.full(n-1,-.6),1)+np.diag(np.full(n-1,-.6),-1)
A=scale[:,None]*T*scale[None,:]
rng=np.random.default_rng(20261001); b=rng.normal(size=n)
plain,hplain,_=cg(A,b)
pre,hpre,_=cg(A,b,True)
reference=np.linalg.solve(A,b)
assert hplain[-1]<1e-10 and hpre[-1]<1e-10
assert np.linalg.norm(pre-reference)/np.linalg.norm(reference)<1e-9
assert len(hpre)<len(hplain)
fig,ax=plt.subplots(1,2,figsize=(10,4.5),layout="constrained")
ax[0].semilogy(hplain,color="#e85d3f",lw=2,label=label("전처리 없음", "No preconditioner"))
ax[0].semilogy(hpre,color="#0f766e",lw=2,label=label("Jacobi 전처리", "Jacobi preconditioner"))
ax[0].axhline(1e-10,color="#94a3b8",ls="--",lw=1)
ax[0].set(xlabel=label("반복 번호", "Iteration"),ylabel=label("원래 계의 상대 잔차", "Original-system relative residual"),
          title=label("좌표 크기 차이를 줄인 효과", "Reducing coordinate scale imbalance"))
ax[0].legend(fontsize=8); ax[0].grid(alpha=.2,which="both")
eig_plain=np.linalg.eigvalsh(A)
scaled=A/np.sqrt(np.diag(A)[:,None]*np.diag(A)[None,:])
eig_pre=np.linalg.eigvalsh(scaled)
ax[1].semilogy(range(1,n+1),eig_plain,".",color="#e85d3f",label=label("원래 행렬", "Original matrix"))
ax[1].semilogy(range(1,n+1),eig_pre,".",color="#0f766e",label=label("대칭 전처리 행렬", "Symmetrically preconditioned"))
ax[1].set(xlabel=label("정렬한 고유값 번호", "Sorted eigenvalue index"),ylabel=label("고유값", "Eigenvalue"),
          title=label("조건수와 분포도 함께 보기", "Look at condition and spectrum"))
ax[1].legend(fontsize=8); ax[1].grid(alpha=.2,which="both")
finish(5,fig,{"small_solution":xs.tolist(),"small_iterations":len(hs)-1,"small_normalized_conjugacy_error":float(normalized_conjugacy),
              "dimension":n,"plain_iterations":len(hplain)-1,"jacobi_iterations":len(hpre)-1,
              "plain_relative_true_residual":float(hplain[-1]),"jacobi_relative_true_residual":float(hpre[-1]),
              "jacobi_relative_solution_error":float(np.linalg.norm(pre-reference)/np.linalg.norm(reference)),
              "plain_condition_number":float(eig_plain[-1]/eig_plain[0]),
              "preconditioned_condition_number":float(eig_pre[-1]/eig_pre[0])})
