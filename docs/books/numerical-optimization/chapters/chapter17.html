제약을 위반할 때 비용을 더하면 무제약 알고리즘을 활용할 수 있다. 그러나 벌점 계수를 크게 하는 것만으로 모든 문제가 해결되지는 않는다. 정확도와 조건수가 서로 충돌하기 때문이다. 증강 라그랑지안은 여기에 승수 추정을 더해, 제약을 지키는 데 필요한 힘을 반복적으로 학습한다.

학습 목표와 부호 약속

  • 이차 벌점의 유한 계수 오차와 조건수 악화를 계산한다
  • 정확 벌점의 “정확”이 뜻하는 범위를 설명한다
  • 등식 증강 라그랑지안의 승수 갱신 부호를 유도한다
  • 내부 하위 문제 오차와 외부 제약 회복을 나누어 점검한다

등식 문제 min⁡f(x)\min f(x)minf(x), c(x)=0c(x)=0c(x)=0에서 L(x,λ)=f(x)−λTc(x)L(x,\lambda)=f(x)-\lambda^Tc(x)L(x,λ)=f(x)−λTc(x)로 정한다. 따라서 KKT 정상성은 ∇f−JTλ=0\nabla f-J^T\lambda=0∇f−JTλ=0이며 등식 승수는 양수와 음수 모두 가능하다. 이 장의 직접 계산은 강하게 볼록인 이차 목적과 선형 등식을 사용한다. 일반 비선형 문제에 대한 전역 보장을 그 작은 예제에서 추론하지 않는다.

17.1 이차 벌점의 유혹과 대가

이차 벌점은 Qρ(x)=f(x)+ρ2∥c(x)∥2Q_\rho(x)=f(x)+\tfrac\rho2\|c(x)\|^2Qρ​(x)=f(x)+2ρ​∥c(x)∥2를 최소화한다. 미분 가능해서 기존 무제약 도구를 적용하기 쉽다. 정상성은 다음과 같다.

∇Qρ=∇f+ρJTc=0.\nabla Q_\rho=\nabla f+\rho J^Tc=0.∇Qρ​=∇f+ρJTc=0.

원래 KKT 식과 비교하면 승수 추정은 λ≈−ρc\lambda\approx-\rho cλ≈−ρc다. 최적 승수가 0이 아니라면 유한한 ρ\rhoρ에서 일반적으로 c=0c=0c=0을 정확히 만족시키지 못한다. 제약 위반을 줄이기 위해 ρ\rhoρ를 크게 해야 하는 이유다. 그러나 “일반적으로”라는 말이 중요하다. 특수 문제나 최적 승수가 0인 상황은 다르게 행동할 수 있다.

선형 등식에서 벌점 헤시안은 ∇2f+ρJTJ\nabla^2f+\rho J^TJ∇2f+ρJTJ다. ρ\rhoρ가 커질수록 제약의 법선 방향 곡률은 커지지만 접선 방향 곡률은 그대로일 수 있다. 긴 좁은 골짜기가 생겨 선형계와 선 탐색이 어려워진다. 제약 위반만 작아지는 대신 계산이 점차 민감해질 수 있으므로 계수를 한 번에 매우 크게 잡는 것은 좋은 기본 전략이 아니다.

17.2 비매끄러운 정확 벌점

절댓값 벌점 Pρ=f+ρ∥c∥1P_\rho=f+\rho\|c\|_1Pρ​=f+ρ∥c∥1​은 제약면에서 꺾인다. 적절한 제약 자격 조건과 국소 최적성 조건 아래, 계수가 승수의 적절한 크기를 넘으면 원래 해가 유한한 벌점 계수에서도 국소 최소가 되는 정확성 성질을 갖는다. 이는 벌점 함수가 모든 점에서 원래 목적과 같다는 뜻도, 아무 초기점에서든 전역해에 간다는 뜻도 아니다.

min⁡t(t−2)210+ρ∣t∣,tρ=max⁡(2−5ρ,0).\min_t\frac{(t-2)^2}{10}+\rho|t|, \qquad t_\rho=\max(2-5\rho,0).tmin​10(t−2)2​+ρ∣t∣,tρ​=max(2−5ρ,0).

꺾인 함수를 매끄러운 함수인 것처럼 일반 뉴턴법에 넣으면 미분 계산이 깨질 수 있다. 부분미분, 보조 변수, 적절한 비매끄러운 최적화 도구가 필요하다. 절댓값을 매끄럽게 근사하면 계산은 편해질 수 있지만 유한 계수의 정확성 성질도 달라진다.

17.3 증강 라그랑지안은 승수를 갱신한다

등식 증강 라그랑지안은 다음과 같다.

Lρ(x,λk)=f(x)−λkTc(x)+ρ2∥c(x)∥2.\mathcal L_\rho(x,\lambda_k) =f(x)-\lambda_k^Tc(x)+\frac\rho2\|c(x)\|^2.Lρ​(x,λk​)=f(x)−λkT​c(x)+2ρ​∥c(x)∥2.

현재 승수로 이 함수를 대략 최소화한 뒤 λk+1=λk−ρc(xk+1)\lambda_{k+1}=\lambda_k-\rho c(x_{k+1})λk+1​=λk​−ρc(xk+1​)로 갱신한다. 부호가 음수인 이유는 처음에 L=f−λTcL=f-\lambda^TcL=f−λTc를 택했기 때문이다. 다른 자료가 f+λTcf+\lambda^Tcf+λTc를 사용하면 승수와 갱신 부호가 모두 바뀐다. 기호만 부분적으로 가져오지 말고 라그랑지안부터 맞추어야 한다.

하위 문제를 정확히 풀었다면 그 정상성은 ∇f−JTλk+ρJTc=0\nabla f-J^T\lambda_k+\rho J^Tc=0∇f−JTλk​+ρJTc=0이다. 갱신식을 대입하면 ∇f−JTλk+1=0\nabla f-J^T\lambda_{k+1}=0∇f−JTλk+1​=0이 된다. 즉 새 승수는 방금 구한 점에서 원래 문제의 정상성을 설명한다. 다음 반복은 남아 있는 제약 위반을 더 줄이는 역할을 한다.

새 모델에서 ρ=1\rho=1ρ=1, λ0=0\lambda_0=0λ0​=0을 고정하면 승수 오차는 한 번마다 1/61/61/6로 줄어든다. 큰 벌점으로 모든 일을 밀어붙이는 대신 잘못된 승수를 차근차근 보정한다. 같은 벌점 계수에서 하위 문제 헤시안 조건수는 계속 6이므로 이 예제에서는 계수를 발산시킬 필요가 없다.

그림 확대

왼쪽은 두 벌점의 제약 위반, 가운데는 이차 벌점의 조건수, 오른쪽은 고정 계수 증강 라그랑지안의 오차다. 직접 계산한 18번의 외부 갱신 뒤 제약 위반은 1.98×10−141.98\times10^{-14}1.98×10−14, 승수 오차는 4.11×10−154.11\times10^{-15}4.11×10−15, 정상성 잔차는 2.22×10−162.22\times10^{-16}2.22×10−16이었다. 절댓값 벌점에서 정확히 0인 값은 로그 그림에만 작은 바닥값으로 표시한다.

17.4 실제 알고리즘에서 추가되는 판단

비선형 하위 문제는 매번 정확히 풀기 어렵다. 초반에는 느슨하게 풀고 제약이 개선될수록 정확도를 높이는 방식을 생각할 수 있다. 하지만 하위 문제 오차가 너무 크면 승수 갱신이 잘못된 정보를 학습한다. 내부 정상성, 원래 제약 위반, 승수 크기를 함께 기록해야 한다.

고정 벌점으로 제약 위반이 충분히 줄지 않으면 계수를 키우는 실용 규칙이 필요하다. 따라서 “증강 라그랑지안은 벌점을 절대 키우지 않는다”는 설명은 틀리다. 중요한 장점은 무조건 무한대로 키우는 부담을 줄일 수 있다는 것이다. 비볼록 하위 문제에서는 국소 최소, 나쁜 정상점, 복수 해가 나타날 수 있으며 시작점의 영향도 남는다.

부등식에는 slack을 도입하거나 투영을 포함한 적절한 증강 형태를 사용한다. c≥0c\ge0c≥0라는 부등식을 무조건 c2c^2c2로 벌주면 이미 충분한 여유가 있는 실행 가능한 점도 제약면으로 끌어당긴다. 부등식 위반은 음수 부분과 관련되므로 등식 공식을 그대로 복사하지 않는다. 승수 비음수성과 상보성을 함께 관리해야 한다.

17.5 방법의 위치와 해석

벌점 계열은 무제약 도구를 활용할 수 있고 구조적 분해에도 도움이 되지만, 그 편의가 조건수와 계수 선택 문제를 없애지는 않는다. 제약이 아주 정확해야 하는 상황에서는 원래 문제 잔차를 직접 확인한다. 벌점 목적이 낮아졌다는 사실만으로 제약 문제의 비용이 좋다고 결론 내리지 않는다.

제약 스케일도 중요하다. ccc를 100c100c100c로 바꾸면 실행 가능 집합은 동일하지만 같은 ρ\rhoρ의 이차 벌점은 10000배 강해진다. 승수의 자연스러운 크기도 달라진다. 물리 단위가 다른 제약을 적절히 정규화하고, 비교 실험에서는 스케일과 벌점 규칙을 같이 기록하는 것이 바람직하다.

"""Original, self-contained numerical experiment. No network or external data.
Run: python chapter17.py --output-dir ./results
Requires NumPy, SciPy and Matplotlib. An installed Korean font is optional.
If unavailable, all plot labels fall back to English; --english forces this mode.
"""
import argparse
import json
import platform
from pathlib import Path
import numpy as np
import scipy
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib import font_manager

parser = argparse.ArgumentParser()
parser.add_argument("--output-dir", type=Path, default=Path("."))
parser.add_argument("--english", action="store_true", help="Use English plot labels")
args = parser.parse_args()
args.output_dir.mkdir(parents=True, exist_ok=True)
font_paths = [Path("/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc")]
font_paths += [Path(f.fname) for f in font_manager.fontManager.ttflist
               if any(s in f.name for s in ("Noto Sans CJK", "Nanum", "Malgun", "AppleGothic"))]
font_path = next((p for p in font_paths if p.exists()), None)
if args.english:
    font_path = None
if font_path is not None:
    font_manager.fontManager.addfont(str(font_path))
font_family = font_manager.FontProperties(fname=str(font_path)).get_name() if font_path else "DejaVu Sans"
plt.rcParams.update({"font.family": font_family,
                     "axes.unicode_minus": False, "font.size": 11,
                     "axes.spines.top": False, "axes.spines.right": False,
                     "figure.facecolor": "#f7f9fc", "axes.facecolor": "#f7f9fc",
                     "axes.prop_cycle": matplotlib.cycler(color=["#156f87", "#e07945", "#7661a9", "#278169"])})

ENGLISH_LABELS = {'이차 벌점': 'Quadratic penalty', '절댓값 벌점': 'Absolute-value penalty', '임계값 0.4': 'Threshold 0.4', '벌점 계수': 'Penalty parameter', '등식 제약 위반': 'Equality violation', '정확성의 차이': 'Penalty exactness', '헤시안 조건수': 'Hessian condition number', '이차 벌점의 대가': 'Conditioning cost', '제약 위반': 'Constraint violation', '승수 오차': 'Multiplier error', '바깥 반복': 'Outer iteration', '오차': 'Error', '고정 계수의 증강 라그랑지안': 'Augmented Lagrangian, fixed penalty'}
def tr(label):
    return label if font_path else ENGLISH_LABELS[label]

def finish(chapter, fig, metrics):
    fig.savefig(args.output_dir / f"chapter{chapter:02d}.png", dpi=160)
    plt.close(fig)
    report = {"chapter": chapter, "plot_language": "ko" if font_path else "en",
              "versions": {"python": platform.python_version(), "numpy": np.__version__,
                           "scipy": scipy.__version__, "matplotlib": matplotlib.__version__},
              "metrics": metrics}
    serialized = json.dumps(report, ensure_ascii=False, allow_nan=False, indent=2)
    (args.output_dir / f"chapter{chapter:02d}-results.json").write_text(serialized + "\n", encoding="utf-8")
    print(json.dumps(report, ensure_ascii=False, allow_nan=False))

a=np.array([2.,-1.]); A=np.array([2.,1.]); b=1.
truth=a-A*(A@a-b)/(A@A); lam_star=-(A@a-b)/(A@A)
rhos=np.logspace(-3,5,100)
penalty=[]; condition=[]; exact=[]
for rho in rhos:
    xp=np.linalg.solve(np.eye(2)+rho*np.outer(A,A),a+rho*b*A)
    penalty.append(abs(A@xp-b)); condition.append(np.linalg.cond(np.eye(2)+rho*np.outer(A,A)))
    residual=max(float(A@a-b)-rho*(A@A),0.)
    xe=a+A*(residual-(A@a-b))/(A@A)
    exact.append(abs(A@xe-b))
lam=0.; rho=1.; al=[]
for k in range(18):
    x=np.linalg.solve(np.eye(2)+rho*np.outer(A,A),a+(lam+rho*b)*A)
    residual=float(A@x-b)
    lam=lam-rho*residual
    al.append([abs(residual),abs(lam-lam_star),np.linalg.norm(x-truth,np.inf)])
metrics={"solution_x":float(x[0]),"solution_y":float(x[1]),"multiplier":float(lam),
         "al_constraint_violation":float(abs(A@x-b)),
         "al_solution_error":float(np.linalg.norm(x-truth,np.inf)),
         "al_multiplier_error":float(abs(lam-lam_star)),
         "al_stationarity":float(np.linalg.norm(x-a-lam*A,np.inf)),
         "largest_penalty_residual":float(penalty[-1]),"largest_penalty_condition":float(condition[-1]),
         "exact_penalty_threshold":float(abs(lam_star)),
         "exact_penalty_error_above_threshold":float(max(v for r,v in zip(rhos,exact) if r>=.4))}
assert max(metrics[k] for k in ("al_constraint_violation","al_solution_error","al_multiplier_error","al_stationarity","exact_penalty_error_above_threshold"))<1e-10
assert abs(penalty[-1]-2/(1+5*rhos[-1]))<1e-10
fig,ax=plt.subplots(1,3,figsize=(10,4.6),layout="constrained")
ax[0].loglog(rhos,penalty,label=tr("이차 벌점"))
ax[0].loglog(rhos,np.maximum(exact,1e-15),label=tr("절댓값 벌점"))
ax[0].axvline(.4,color="#7661a9",ls=":",label=tr("임계값 0.4"))
ax[0].set(xlabel=tr("벌점 계수"),ylabel=tr("등식 제약 위반"),title=tr("정확성의 차이")); ax[0].legend(fontsize=8)
ax[1].loglog(rhos,condition,color="#e07945")
ax[1].set(xlabel=tr("벌점 계수"),ylabel=tr("헤시안 조건수"),title=tr("이차 벌점의 대가"))
al=np.maximum(np.array(al),1e-16)
ax[2].semilogy(np.arange(1,len(al)+1),al[:,0],"o-",ms=3,label=tr("제약 위반"))
ax[2].semilogy(np.arange(1,len(al)+1),al[:,1],"s--",ms=3,label=tr("승수 오차"))
ax[2].set(xlabel=tr("바깥 반복"),ylabel=tr("오차"),title=tr("고정 계수의 증강 라그랑지안")); ax[2].legend(fontsize=8)
finish(17,fig,metrics)
