출처와 이용 안내

이 사이트는 Rawlings·Mayne·Diehl의 Model Predictive Control: Theory, Computation, and Design, 2판 1쇄(2017)를 참고한 비공식 한국어 학습 노트입니다. 설명·계산 예제·시각화는 학습 목적에 맞게 새로 구성했으며, 교재에서 가져온 모델·예제는 해당 출처를 별도로 표시합니다. 공식 번역본이나 저자·출판사가 승인한 자료가 아닙니다. 원문·도판·원본 PDF는 재배포하지 않으며, 원전은 저자 공식 사이트에서 확인할 수 있습니다. 원전의 저작권은 권리자에게 있고, 출처 표시는 재사용 허락을 뜻하지 않습니다. AI의 도움으로 작성되어 오류가 있을 수 있으니 수식·가정·계산은 원전 및 독립 계산으로 확인해 주세요.

  • 저자 공식 교재 사이트
  • 참고 판본: Rawlings, Mayne, Diehl (2017), Model Predictive Control: Theory, Computation, and Design, 2nd edition, 1st printing

교재 모델을 이용한 계산에는 해당 예제·쪽수를 표시하고, 이 사이트에서 새로 구성한 문제는 학습용 보충 문제로 표시합니다. 일반 수학식의 조판, 직접 제작한 개념 도식, 수치 재계산은 원전의 저작권이나 제3자 자료의 사용 조건을 변경하지 않습니다. 별도의 포괄적 재사용 허락을 부여하는 자료가 아닙니다.

수식과 시각화

본문 수식은 KaTeX로 미리 조판하며 화면 낭독기를 위한 MathML을 포함합니다. 도식 17개와 수식 카드 32개는 학습 설명을 위해 새로 제작했습니다. 원전의 도판이나 스캔 이미지는 포함하지 않습니다.

소스와 재현

학습 노트 원문, 웹사이트 생성 코드, 독립 실행 예제와 시각화 재생성 스크립트는 GitHub 저장소에서 확인할 수 있습니다. 각 장의 Python 예제는 다른 장이나 외부 저장소를 불러오지 않고 단독 실행할 수 있습니다. 설치 이후 실행에는 네트워크 연결이 필요하지 않습니다.

KaTeX는 MIT 라이선스에 따라 포함됩니다. 해당 라이선스는 수식 표시 소프트웨어에만 적용되며, 교재나 이 사이트의 학습 자료에 대한 포괄적인 이용 허락을 뜻하지 않습니다. KaTeX 라이선스 보기
